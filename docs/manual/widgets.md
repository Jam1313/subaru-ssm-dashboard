# Subaru SSM Dashboard (kg.forester.sg) — справочник по всем экранам и виджетам

Источник: исходники `app/src/main/java/kg/forester/sg` (рабочее дерево на момент чтения, включая незакоммиченные правки в `ui/HomeScreen.kt`, `ui/DriveScreen.kt`, `ui/Components.kt`, новые `ui/Info.kt`, `ui/InfoTexts.kt`). Ссылки вида `файл:строка` даны относительно этого каталога.

Обозначения в нормах: «ориентир» = типичное значение для исправного Forester, в коде приложения не зашито и зависит от машины/условий. Там, где в коде есть порог, он указан как «порог в приложении».

## 0. Общие сведения

### 0.1 Откуда берутся данные

| Источник | Что даёт | Где в коде |
|---|---|---|
| ЭБУ двигателя (SSM2, адрес 0x10) | 23 параметра одним запросом A8 (+2 необязательных — уровень топлива) | `ssm/EcuParams.kt:83-87`, `service/EcuService.kt:320-360` |
| Блок АКПП (TCU 4EAT, SSM2 адрес 0x18) | 10 параметров + положение селектора | `ssm/TcuParams.kt`, `service/EcuService.kt:397-419` |
| GPS магнитолы/телефона | скорость, высота, точность, спутники, курс | `service/EcuService.kt:437-463` |
| Вычисления приложения | расход, запас хода, поездки, стиль вождения, АКБ, откаты зажигания | `service/TripTracker.kt`, `BatteryMonitor.kt`, `KnockWatch.kt`, `FuelSensorCal.kt` |
| Система FYT/Teyes (`com.syu.ms`) | музыка, BT-музыка, радио | `service/Fyt.kt` |

Датчики телефона (акселерометр и т.п.) **не используются**. Ускорения считаются по скорости.

### 0.2 Частота опроса
- KKL-кабель / OpenPort 2.0: весь список адресов одним запросом A8 на 4800 бод (`ssm/SsmClient.kt:111-117`, `149-171`), т.е. несколько обновлений в секунду (точная частота в коде не задана, зависит от линии).
- Bluetooth ELM327: в один кадр помещается только **один адрес** (`ssm/Elm327.kt:81`, `124`), поэтому 23 адреса читаются по одному. Текст в настройках: «Данные обновляются примерно раз в секунду» (`ui/CarSetup.kt:174-175`).
- АКПП опрашивается на каждом 3-м цикле ЭБУ (`service/EcuService.kt:353`). Если АКПП не ответила на init, следующая попытка через 60 с (`service/EcuService.kt:402-405`).
- GPS: запрос обновлений раз в 1 с (`service/EcuService.kt:461`).
- Буфер живых графиков: последние 240 снимков ЭБУ (`EcuService.kt:348`) и 120 снимков АКПП (`EcuService.kt:417`). Подпись «последняя минута» верна только при ~4 Гц; с ELM327 окно получается в несколько раз длиннее.

### 0.3 Формулы декодирования ЭБУ (`ssm/EcuParams.kt:115-146`)

`x` — сырой байт 0…255, `x16` — 16-битное значение из двух байтов.

| Параметр | Адрес | Формула | Ед. | Строка |
|---|---|---|---|---|
| Темп. ОЖ | 0x08 | `x − 40` | °C | 122 |
| Обороты | 0x0E/0x0F | `x16 / 4` | об/мин | 123 |
| Скорость (ЭБУ) | 0x10 | `x` | км/ч | 124 |
| УОЗ | 0x11 | `(x − 128) / 2` | ° | 125 |
| Темп. впуска | 0x12 | `x − 40` | °C | 126 |
| MAF | 0x13/0x14 | `x16 / 100` | г/с | 127 |
| Дроссель | 0x15 | `x · 100 / 255` | % | 128 |
| Напряжение | 0x1C | `x · 0,08` | В (шаг 0,08 В) | 129 |
| Время впрыска | 0x20 | `x · 0,256` | мс | 130 |
| Коррекция детонации | 0x22 | `(x − 128) / 2` | ° (шаг 0,5°) | 131 |
| Атм. давление | 0x23 | `x` | кПа | 132 |
| Наддув (относит.) | 0x24 | `x − 128` | кПа | 133 |
| Коррекция A/F #1 | 0x09 | `(x − 128) · 100 / 128` | % | 134 |
| Обучение A/F #1 | 0x0A | `(x − 128) · 100 / 128` | % | 135 |
| Лямбда (A/F-датчик) | 0x46 | `x / 128`, при `x = 0` — нет данных | λ | 136 |
| Wastegate | 0x30 | `x · 100 / 255` | % | 137 |
| Педаль газа | 0x29 | `x · 100 / 255` | % | 138 |
| Абс. давление (MAP) | 0x0D | `x` | кПа | 139 |
| AVCS (впуск) | 0x3C | `x − 50` | ° | 140 |
| Генератор (duty) | 0x3A | `x` | % | 141 |
| Привод дросселя | 0xFA | `(x − 128) · 100 / 128` | % | 142 |
| Датчик топлива, В | 0x2E (необяз.) | `x / 50` | В | 143 |
| Датчик топлива, Ом | 0x10D (необяз.) | `x · 2` | Ом | 144 |

Производные величины (`ssm/EcuParams.kt:31-49`):
- **AFR** = `λ · 14,7` (строка 31).
- **Давление относительно атмосферы** `gaugeKpa` = `MAP − ATM`; если MAP или ATM нет, берётся байт 0x24 (строки 34-35). Отрицательное значение = разрежение.
- **Наддув, бар** `boostBar` = `max(0, gaugeKpa) / 100` (строка 38). Отрицательным не бывает.
- **Разрежение, кПа** `vacuumKpa` = `max(0, −gaugeKpa)` (строка 41).
- **Нагрузка, г/об** = `MAF · 60 / обороты`, только при оборотах > 300 (строки 44-45).
- **Загрузка форсунок, %** = `время_впрыска_мс · обороты / 1200` (строки 48-49). Формула для одного впрыска на 2 оборота коленвала.

Если ЭБУ в init-ответе не заявил A/F-датчик, лямбда принудительно обнуляется, и AFR показывается как «—» (`service/EcuService.kt:328`, `343-345`).

Подбор адресов: сначала весь список. Если ЭБУ молчит — только адреса, отмеченные в байтах возможностей, потом перебор по одному (`service/EcuService.kt:372-394`). Отсутствующие параметры показываются «—».

### 0.4 Формулы АКПП (`ssm/TcuParams.kt:47-73`)

| Параметр | Адрес | Формула | Ед. |
|---|---|---|---|
| Темп. ATF | 0x56 (новые TCU) | `x − 50` | °C |
| Темп. ATF | 0x49 (старые TCU) | таблица FreeSSM `ATF_TABLE[x]` (`TcuParams.kt:76-93`) | °C |
| Передача | 0x4A | `x + 1` | — |
| Обороты турбины | 0x4F | `x · 32` | об/мин (шаг 32) |
| Давление в линии | 0x4B | `x / 2` | % (duty соленоида) |
| Блокировка (lock-up) | 0x4C | `x / 2` | % |
| Муфта полного привода | 0x4D | `x / 2` | % |
| Скорость перед. колёс | 0x48 | `x` | км/ч |
| Скорость задн. колёс | 0x51 | `x` | км/ч |
| Тормоз/сцепление | 0x50 | `x / 2` | % (на экране не показывается) |
| Селектор | 0x6B | биты: 0x02 R, 0x04 D, 0x08 «3», 0x10 «2», 0x20 «1», иначе «P/N» | — |

Если есть 0x56, используется он, иначе таблица для 0x49 (`TcuParams.kt:50`). Байт селектора 0x6B есть не во всех таблицах возможностей; он опрашивается всегда, а расшифровка битов проверена на машине автора (`TcuParams.kt:43`).

### 0.5 GPS (`service/EcuService.kt:437-447`)
- Скорость = `Location.speed · 3,6` км/ч (0, если скорости нет).
- Высота = `Location.altitude`. Android отдаёт высоту над эллипсоидом WGS-84, а не над уровнем моря, поэтому она может отличаться от высоты на картах на десятки метров.
- Точность = `Location.accuracy` м (99, если нет).
- Спутники = `extras["satellites"]`. На многих устройствах это поле пустое, тогда показывается 0.
- Курс = `bearing` (null на месте).
- «Свежий» фикс для расчётов: не старше 3 с и точность < 15 м (`service/TripTracker.kt:85`).

### 0.6 Цвета (`ui/Components.kt:49-64`)
Акцентная полоса — градиент синий→фиолетовый. Предупреждение — оранжевое число и полоса оранжево-красная (`ui/HomeScreen.kt:199`, `205-208`).

## 1. Общие элементы интерфейса

### 1.1 Верхняя панель (статус-бар) — `MainActivity.kt:398-426`

#### Логотип и название машины
- **Что показывает:** логотип Subaru; крупно — «Название в шапке» (`carTitle`, по умолчанию «FORESTER SG5»), ниже — «Подпись» (`carSub`, по умолчанию «2003   EJ20 turbo»).
- **Источник:** настройки (`data/Repo.kt:155-161`). Меняется при выборе модели или вручную (Настройки → «Авто и адаптер»).
- **Как считается:** не вычисляется.

#### Напряжение
- **Что показывает:** напряжение бортсети, 1 знак после запятой, «V».
- **Источник:** ЭБУ 0x1C.
- **Как считается:** `x · 0,08` (`ssm/EcuParams.kt:129`), вывод `MainActivity.kt:414-415`.
- **Нормы / подсказки:** заглушен — 12,4–12,7 В; работает — 13,5–14,7 В (ориентир).
- **Примечания:** ЭБУ меряет с шагом 0,08 В. Цветом не подсвечивается.

#### Температура ОЖ
- **Что показывает:** °C, без порогов и цвета (`MainActivity.kt:417-418`).
- **Источник:** ЭБУ 0x08, `x − 40`.
- **Нормы / подсказки:** прогретый мотор 85–100 °C (ориентир).

#### Значок связи
- **Что показывает:** зелёный значок USB, если связь с ЭБУ есть (`LinkState.CONNECTED`), иначе оранжевый «отключено» (`MainActivity.kt:420-421`).
- **Источник:** состояние сервиса (`service/EcuService.kt`). Текст причины (нет кабеля, нет разрешения, ЭБУ не отвечает, демо) виден в Настройках → «Связь».

#### Часы
- **Что показывает:** время ЧЧ:ММ устройства. Обновляется раз в 5 с (`MainActivity.kt:402-403`, `423`).

### 1.2 Нижняя панель — `MainActivity.kt:428-446`

#### Топливо (запас хода)
- **Что показывает:** запас хода в км и полосу уровня топлива.
- **Источник:** вычисление `TripTracker` (раздел 14.5).
- **Как считается:** текст = `rangeKm`. Полоса = `остаток_л / объём_бака` (`MainActivity.kt:439`). Если объём бака 0, полосы нет.
- **Примечания:** «—», пока остаток неизвестен: не было ни одной заправки, не введено «Сейчас в баке» и не обучен датчик уровня.

#### Темп. ОЖ
- **Что показывает:** °C и полосу.
- **Как считается:** полоса = `ОЖ / 110` от нуля (`MainActivity.kt:440`). Шкала отличается от плитки на Главной (там 40…110).

#### Напряжение
- **Как считается:** полоса = `(В − 10) / 5`, шкала 10…15 В (`MainActivity.kt:441`). Без данных полоса пустая.

#### Впуск
- **Что показывает:** температура воздуха на впуске, °C, без полосы (`MainActivity.kt:442`).

#### Высота
- **Что показывает:** высота, м.
- **Как считается:** если есть GPS, берётся его высота. Иначе барометрическая формула по атмосферному давлению ЭБУ: `h = 44330 · (1 − (P_атм / 101,325)^0,1903)` (`MainActivity.kt:443`).
- **Примечания:** о высоте GPS см. 0.5. Барометрическая высота зависит от погоды: ±1 кПа ≈ ±80 м (ориентир).

### 1.3 Навигационная панель (рейл / полоса) — `MainActivity.kt:295-396`
- **Что показывает:** кнопки экранов «Главная, Динамика, Медиа, Расход, АКПП, АКБ, Ошибки, Лог, Приложения, Настройки» (`MainActivity.kt:70-81`). Ниже, после разделителя, — пользовательские кнопки быстрого запуска (синие иконки).
- **Правила видимости** (`MainActivity.kt:295-305`):
  - «АКПП» скрыт, если коробка = «Механика».
  - «Медиа» есть только на магнитолах FYT/Teyes (установлен пакет `com.syu.ms`).
  - «Приложения» скрыт на телефонах (smallestWidth < 600 dp).
- **Положение:** слева / справа / сверху / снизу (Настройки → Основные). Сверху и снизу панель горизонтальная, с прокруткой.
- Кнопка «Назад» всегда ведёт на «Главную» (`MainActivity.kt:213-215`).
- При старте открывается «Главная», если приложение назначено домашним экраном, иначе «Расход» (`MainActivity.kt:211`).

### 1.4 Голосовой тост — `ui/VoiceUi.kt:48-68`
Плашка с микрофоном вверху экрана примерно на 2,6 с. Показывает, что понял голосовой ассистент: «Расход», «Не понял: …», «Слушаю…».

### 1.5 Заставка и масштаб
- Заставка 1,8 с, затем затухание 0,6 с (`MainActivity.kt:137-153`).
- Масштаб «Авто»: плотность уменьшается так, чтобы макет 1180×660 dp поместился на экран. Только в альбомной ориентации и не меньше 50 % от исходной (`MainActivity.kt:160-178`). Вручную: 80–120 % (`ui/CarSetup.kt:159`).

## 2. Главная (`ui/HomeScreen.kt`)

Экран состоит из блока «3D-машина + два прибора» и сетки плиток в 5 колонок. Размер 3D-блока: 0 — скрыт, 1 — обычный, 2 — большой, 3 — макс. Вес блока относительно одного ряда плиток — 0 / 1,9 / 3,0 / 4,6 (`data/HomeLayout.kt:50-55`).

### 2.1 Тахометр
- **Что показывает:** обороты двигателя. Стрелка, шкала 0–7 (×1000), число в центре.
- **Источник:** ЭБУ 0x0E/0x0F.
- **Как считается:** `x16 / 4`. Прибор: максимум 7000, крупные деления через 1000, мелкие через 500, красная зона от 6000 (`ui/HomeScreen.kt:99`). Шкала 270° (`ui/Gauges.kt:147-149`). Когда значение ≥ 6000, светящаяся дуга становится оранжево-красной (`ui/Gauges.kt:171-172`).
- **Нормы / подсказки:** холостой ход прогретого мотора ≈ 650–800 об/мин (ориентир). На холодном моторе выше.
- **Примечания:** анимация стрелки 240 мс. Долгое нажатие на прибор открывает выбор дизайна (2.4).

### 2.2 Спидометр
- **Что показывает:** скорость по ЭБУ, км/ч. Шкала 0–200, деления через 20, без красной зоны (`ui/HomeScreen.kt:103`).
- **Источник:** ЭБУ 0x10.
- **Примечания:** показывается **сырая скорость ЭБУ без GPS-коррекции** `speedK`. Для пробега и расхода используется скорректированная (14.6), поэтому стрелка может немного отличаться от расчётного пробега.

### 2.3 3D-машина (`ui/CarViewer.kt`)
- **Что показывает:** вращающаяся 3D-модель (SG5 или SH) с номерным знаком и неоновой подсветкой. В движении включаются дорога, полосы скорости и эффекты выхлопа.
- **Источник:** обороты, скорость ЭБУ, дроссель, наддув, курс GPS.
- **Как считается:**
  - **Стоянка / движение:** «едет», если скорость ЭБУ ≥ 3 км/ч (`CarViewer.kt:182`, `243`). На стоянке машина стоит, её можно крутить пальцем. В движении она плавно поворачивается к виду сзади: кадр `driveFrame`, по умолчанию 43 (`CarViewer.kt:60`, `185-193`). После касания пальцем 4 с автоповорота нет.
  - **Повороты:** курс GPS учитывается при скорости GPS ≥ 10 км/ч. Угловая скорость = Δкурс / Δt, ограничена ±30 °/с, сглаживается коэффициентом 0,45 (`CarViewer.kt:163-173`). Поворот = `yaw / 22`, ограничен ±1. Камера сдвигается максимум на ±3 кадра (`CarViewer.kt:175`, `190`).
  - **Подсветка пола:** яркость = `обороты / 7000` (`CarViewer.kt:251`).
  - **Камера отстаёт при разгоне:** масштаб = `1 − clamp(ускорение/12, −0,6..1) · 0,07`, где ускорение в км/ч за секунду (`CarViewer.kt:245`).
  - **Хлопок в выхлопе (оранжевое пламя):** за последние 0,4 с дроссель упал больше чем на 25 п.п. при оборотах > 2800 (сброс газа) **или** обороты упали больше чем на 600 при дросселе > 50 % и оборотах > 2500 (переключение под нагрузкой). Только при скорости ≥ 3 км/ч (`CarViewer.kt:228-230`).
  - **Голубое мерцание турбины:** интенсивность = `наддув_бар / 0,9`. Видно, когда > 0,15, то есть с ≈ 0,14 бар (`CarViewer.kt:250`, `386`).
  - **«Нитро» (размытие по краям):** `clamp((наддув − 0,35)/0,5 + (ускорение − 6)/10, 0..1)` (`CarViewer.kt:247-249`).
- **Примечания:** чисто декоративный элемент, диагностического смысла нет. Эффекты выхлопа рисуются только в кадре вида сзади. Цвет кузова и модель выбираются в настройках (12.2).

### 2.4 Дизайн приборов (`ui/Gauges.kt:58-115`, `233-272`)
Долгое нажатие на тахометр или спидометр открывает окно с живыми превью. Тахометр и спидометр настраиваются отдельно (`data/Repo.kt:194-200`). Варианты: «Неон» (по умолчанию), «Underground», «Кислота», «STI», «Белая классика», «Карбон», «Ретро», «Минимал». Влияет только на внешний вид.

### 2.5 Редактор главного экрана (`ui/HomeEditor.kt`)
- Вход: долгое нажатие на любую плитку или карандаш в углу 3D-блока.
- Панель: размер 3D-блока (Скрыть/Обычный/Большой/Макс.), «Добавить виджет» (список скрытых плиток), «Сбросить» (заводская раскладка и обычный размер 3D), «Готово».
- На плитке: ← → переставить (меняется местами с соседней видимой), − / + ширина 1…3 колонки, ✕ скрыть.
- Плитки укладываются в ряды по 5 колонок слева направо (`data/HomeLayout.kt:38-47`).
- Заводская раскладка: 15 включённых плиток — coolant, intake, battery, throttle, maf, afr, afcorr, aflearn, timing, knock, inj, wgdc, fuel, boost, gps. Ещё 8 выключены: pedal, avcs, map, atm, alt, atf, per100, range (`data/HomeLayout.kt:14-20`).

### 2.6 Плитки Главной (`ui/HomeScreen.kt:145-170`)

Общее для всех плиток (`BarCard`, `HomeScreen.kt:190-215`): число, единица и полоса. Полоса = `(значение − min) / (max − min)` с обрезкой до 0…1. При срабатывании порога число становится оранжевым, а полоса оранжево-красной. Нет данных — «—».

#### Темп. ОЖ (`coolant`)
- **Что показывает:** температура охлаждающей жидкости.
- **Источник:** ЭБУ 0x08.
- **Как считается:** `x − 40`. Шкала 40…110 °C. Предупреждение при > 102 °C (`HomeScreen.kt:146`).
- **Нормы / подсказки:** прогретый мотор 85–100 °C (ориентир). Выше 102 °C — повод проверить вентилятор, термостат и уровень ОЖ.
- **Примечания:** формат без десятых.

#### Темп. впуска (`intake`)
- **Источник:** ЭБУ 0x12, `x − 40`.
- **Как считается:** шкала −20…70 °C. Предупреждение при > 55 °C (`HomeScreen.kt:147`).
- **Нормы / подсказки:** в движении на несколько градусов выше уличной. В пробке и после остановки заметно выше (ориентир). Датчик стоит в корпусе MAF, то есть до турбины и интеркулера: показывает температуру воздуха на входе, а не после интеркулера.

#### Напряжение (`battery`)
- **Источник:** ЭБУ 0x1C, `x · 0,08`.
- **Как считается:** шкала 10…15 В. Предупреждение при < 12,0 В (`HomeScreen.kt:148`).
- **Нормы / подсказки:** при работающем двигателе 13,5–14,7 В (ориентир), заглушен 12,4–12,7 В. Подробный разбор — экран АКБ.

#### Дроссель (`throttle`)
- **Источник:** ЭБУ 0x15, `x · 100/255`.
- **Как считается:** шкала 0…100 %, без порогов (`HomeScreen.kt:149`).
- **Примечания:** это положение заслонки по датчику, а не педали. На машинах с электронной заслонкой (SH) педаль и заслонка различаются, см. «Педаль газа».

#### MAF (`maf`)
- **Что показывает:** массовый расход воздуха.
- **Источник:** ЭБУ 0x13/0x14, `x16 / 100`.
- **Как считается:** шкала 0…150 г/с (`HomeScreen.kt:150`).
- **Нормы / подсказки:** прогретый холостой ход ≈ 2,5–4 г/с (ориентир).
- **Примечания:** на этом значении построен расчёт расхода топлива (14.1).

#### AFR (`afr`)
- **Что показывает:** соотношение воздух/топливо по широкополосному A/F-датчику.
- **Источник:** ЭБУ 0x46 (λ).
- **Как считается:** `AFR = (x/128) · 14,7`. Шкала 10…20, без порогов (`HomeScreen.kt:151`, `EcuParams.kt:31`, `136`).
- **Нормы / подсказки:** на холостом и при ровном движении ≈ 14,7 (стехиометрия, колебания ±0,5). При полном газе богаче: на турбо примерно 10,5–12, на атмосферном около 12,5–13. При сбросе газа (отсечка) уходит в «бедно» (ориентир).
- **Примечания:** «—», если ЭБУ не заявил A/F-датчик (`EcuService.kt:345`).

#### Коррекция A/F (`afcorr`)
- **Что показывает:** кратковременная топливная коррекция #1.
- **Источник:** ЭБУ 0x09.
- **Как считается:** `(x − 128) · 100/128`. Шкала −25…+25 %. Предупреждение при |значение| > 15 % (`HomeScreen.kt:152`).
- **Нормы / подсказки:** в замкнутой петле колеблется в пределах примерно ±10 % вокруг нуля (ориентир).

#### Обучение A/F (`aflearn`)
- **Что показывает:** долговременная (выученная) коррекция #1.
- **Источник:** ЭБУ 0x0A.
- **Как считается:** `(x − 128) · 100/128`. Шкала −25…+25 %. Предупреждение при |значение| > 10 % (`HomeScreen.kt:153`).
- **Нормы / подсказки:** хорошо — в пределах ±5 % (ориентир). Большой плюс — подсос воздуха мимо MAF, слабый бензонасос или грязные форсунки. Большой минус — переобогащение.
- **Примечания:** сбрасывается при сбросе ошибок ЭБУ (раздел 7).

#### УОЗ (`timing`)
- **Что показывает:** итоговый угол опережения зажигания.
- **Источник:** ЭБУ 0x11.
- **Как считается:** `(x − 128) / 2`. Шкала −10…50°, без порогов (`HomeScreen.kt:154`).
- **Нормы / подсказки:** холостой ход порядка 10–20°, лёгкая нагрузка 25–40°, полный газ на турбо намного меньше (ориентир).

#### Коррекция детонации (`knock`)
- **Что показывает:** текущий откат угла по датчику детонации.
- **Источник:** ЭБУ 0x22.
- **Как считается:** `(x − 128) / 2`. Шкала −10…+2°. Предупреждение при < −2° (`HomeScreen.kt:155`).
- **Нормы / подсказки:** норма — 0. Редкие откаты на 0,5–2° под нагрузкой допустимы. Частые или глубже 3° — разбираться (текст приложения, `DriveScreen.kt:223-225`).
- **Примечания:** подсчёт откатов за поездку — на экране «Динамика» (3.5) и в 14.8.

#### Впрыск (`inj`)
- **Что показывает:** длительность импульса форсунки.
- **Источник:** ЭБУ 0x20.
- **Как считается:** `x · 0,256`. Шкала 0…20 мс (`HomeScreen.kt:156`).
- **Нормы / подсказки:** холостой ход прогретого мотора ≈ 2–3,5 мс (ориентир). Значение < 0,2 мс при оборотах > 1100 приложение считает отсечкой топлива (14.1).

#### Wastegate (`wgdc`)
- **Что показывает:** скважность соленоида управления наддувом.
- **Источник:** ЭБУ 0x30.
- **Как считается:** `x · 100/255`. Шкала 0…100 % (`HomeScreen.kt:157`).
- **Нормы / подсказки:** на холостом и без нагрузки около 0. Растёт под наддувом. У атмосферного EJ25 параметр не имеет смысла (ориентир).

#### Расход, л/ч (`fuel`, заголовок на плитке — «Расход»)
- **Что показывает:** мгновенный расход в литрах в час.
- **Источник:** вычисление (14.1).
- **Как считается:** `instLh` из `TripTracker`, сглаженный. Шкала 0…40 л/ч (`HomeScreen.kt:158`).
- **Нормы / подсказки:** прогретый холостой ход ≈ 0,7–1,2 л/ч (ориентир; турбо EJ20 и EJ25 близки).

#### Наддув (`boost`)
- **Что показывает:** избыточное давление во впуске.
- **Источник:** MAP − атм. давление (ЭБУ 0x0D, 0x23); при их отсутствии — 0x24.
- **Как считается:** `max(0, MAP − ATM) / 100` бар. Шкала 0…1,2 бар (`HomeScreen.kt:159`, `EcuParams.kt:34-38`).
- **Нормы / подсказки:** на стоковом EJ20 турбо пиковый наддув порядка 0,7–0,9 бар (ориентир). У атмосферного EJ25 всегда 0, разрежение видно на экране «Динамика».

#### GPS (`gps`)
- **Что показывает:** скорость по GPS и строку «спутников N, ±X м» или «нет сигнала».
- **Источник:** GPS.
- **Как считается:** `speed · 3,6`. Шкала 0…200 км/ч (`HomeScreen.kt:160-161`).
- **Примечания:** спутников может быть 0, если прошивка их не сообщает (0.5).

#### Педаль газа (`pedal`, по умолчанию выключена)
- **Источник:** ЭБУ 0x29, `x · 100/255`. Шкала 0…100 % (`HomeScreen.kt:162`).
- **Примечания:** есть только на ЭБУ с электронной педалью. Иначе «—».

#### AVCS (`avcs`)
- **Что показывает:** угол фазовращателя впускного распредвала.
- **Источник:** ЭБУ 0x3C, `x − 50`. Шкала −10…50° (`HomeScreen.kt:163`).
- **Нормы / подсказки:** на холостом около 0, под нагрузкой и на средних оборотах десятки градусов (ориентир).
- **Примечания:** у EJ253 (SH, атмосферный SOHC) системы AVCS нет, ожидается «—» или мусор (ориентир).

#### Абс. давление (`map`)
- **Что показывает:** абсолютное давление во впускном коллекторе.
- **Источник:** ЭБУ 0x0D, `x` кПа. Шкала 20…220 кПа (`HomeScreen.kt:164`).
- **Нормы / подсказки:** холостой ход около 30–40 кПа (ориентир). Заглушенный мотор при включённом зажигании — равно атмосферному.

#### Атм. давление (`atm`)
- **Источник:** ЭБУ 0x23, `x` кПа. Шкала 70…105 (`HomeScreen.kt:165`).
- **Нормы / подсказки:** ≈ 101 кПа на уровне моря, падает примерно на 1 кПа на каждые 80–90 м высоты (ориентир).

#### Генератор (`alt`)
- **Что показывает:** скважность управления генератором от ЭБУ.
- **Источник:** ЭБУ 0x3A, `x` %. Шкала 0…100 (`HomeScreen.kt:166`).
- **Примечания:** есть не на всех ЭБУ. На SG, вероятно, «—» (ориентир).

#### Темп. ATF (`atf`)
- **Источник:** АКПП (0x56 или 0x49).
- **Как считается:** шкала 0…130 °C. Предупреждение при > 110 °C (`HomeScreen.kt:167`).
- **Нормы / подсказки:** см. экран АКПП, раздел 5.2.

#### Расход, л/100 (`per100`, заголовок на плитке — «Расход»)
- **Что показывает:** мгновенный расход на 100 км.
- **Как считается:** `instPer100 = л/ч / скорость · 100`, только при скорости ≥ 20 км/ч, иначе «—» (`TripTracker.kt:246`). Шкала 0…30 (`HomeScreen.kt:168`).

#### Запас хода (`range`)
- **Как считается:** `rangeKm` (14.5). Шкала 0…800 км (`HomeScreen.kt:169`).

## 3. Динамика (`ui/DriveScreen.kt`)

### 3.1 Верхний ряд — мини-приборы (`DriveScreen.kt:56-60`)
У каждого: число, полоса `(значение − min)/(max − min)`, подписи min/max, если хватает высоты. Порогов и цвета предупреждения нет.

#### Педаль газа
- **Источник:** ЭБУ 0x29. Шкала 0…100 %.

#### Дроссель
- **Источник:** ЭБУ 0x15. Шкала 0…100 %.

#### Наддув
- **Что показывает:** наддув, бар, 0…1,2. При разрежении больше 1 кПа строка «разрежение N кПа».
- **Как считается:** `boostBar`. Подпись = `vacuumKpa = max(0, ATM − MAP)`, показывается при > 1 кПа (`DriveScreen.kt:58`).
- **Нормы / подсказки:** на холостом разрежение около 60–70 кПа (ориентир).

#### Нагрузка
- **Что показывает:** граммы воздуха на оборот.
- **Как считается:** `MAF · 60 / обороты`, при оборотах > 300 (`EcuParams.kt:44-45`). Шкала 0…2,5 г/об.
- **Нормы / подсказки** (ориентир): холостой ход ≈ 0,2–0,3 г/об. Предел атмосферного 2,0–2,5-литрового мотора ≈ 1,1–1,4 г/об, у турбо EJ20 под наддувом заметно выше.

#### Детонация (карточка откатов) — `DriveScreen.kt:161-185`
- **Что показывает:** крупно — текущая коррекция детонации. Если она < 0, число красное и пульсирует, иначе зелёное «нет». Ниже — «За поездку: N · макс X°» или «За поездку: не было».
- **Источник:** ЭБУ 0x22 и счётчик `KnockWatch` (14.8).
- **Как считается:** «активно» = коррекция < 0, включая −0,5° (`DriveScreen.kt:162`). Счётчик учитывает только откаты от −1° и глубже (`data/Knock.kt:28`).
- **Нажатие** открывает «Откаты зажигания за поездку»: время, глубина (красная при ≤ −3°, иначе оранжевая — `DriveScreen.kt:207`), обороты, нагрузка, дроссель, скорость, длительность или «идёт сейчас».
- **Нормы / подсказки** (текст приложения, `DriveScreen.kt:223-225`): редкие откаты на 1–2° под нагрузкой — обычная работа ЭБУ. Разбираться стоит, если откаты глубже 3°, частые или идут на прогретом моторе при ровной езде.

### 3.2 Графики (`DriveScreen.kt:63-88`)
Живые линии по буферу последних 240 снимков (0.2). Справа точка последнего значения, в легенде текущее значение.

| Заголовок | Линии | Шкала |
|---|---|---|
| Педаль и дроссель, % | педаль (фиолетовая), дроссель (синяя) | 0…100 |
| Наддув, бар | `boostBar` (зелёная) | 0…1,2 |
| Смесь (AFR) | AFR (оранжевая) | 10…20 |
| Зажигание и детонация, ° | УОЗ (синяя), коррекция детонации (красная), пунктир нуля | −10…45 |

Пропуски данных рисуются разрывом линии (`ui/Components.kt:303`).

### 3.3 Нижний ряд плиток (`DriveScreen.kt:90-95`)

| Плитка | Источник и формула | Ед. |
|---|---|---|
| AVCS (впуск) | 0x3C, `x − 50` | ° |
| Загрузка форсунок | `время_впрыска · обороты / 1200` (`EcuParams.kt:48-49`) | % |
| MAF | 0x13/14, `/100` | г/с |
| Привод дросселя | 0xFA, `(x − 128)·100/128` | % |

- **Нормы / подсказки:** загрузка форсунок — общепринятый безопасный предел около 80–85 % (ориентир). На холостом единицы процентов.
- **Примечания:** плитка «Абс. давление» здесь показывает MAP **и** атмосферное, а одноимённая плитка Главной — только MAP (см. раздел 16).

## 4. Расход (`ui/FuelScreen.kt`)

### 4.0 Шапка
#### Вкладки
«Текущий», «История», «Заправки», «Стиль», «Поездки».

#### Средний расход (весь период) — `FuelScreen.kt:79-93`
- **Источник:** база поездок (`data/Db.kt:136-139`).
- **Как считается:** `Σтопливо / Σкм · 100` по всем сохранённым поездкам, если Σкм > 1. Иначе показывается сожжённый объём и «л · пробега пока нет».
- **Примечания:** топливо стоянок (поездки без пробега) входит в числитель, поэтому прогрев и холостой ход повышают среднее.

### 4.1 Вкладка «Текущий»

#### Текущий расход (кольцо) — `FuelScreen.kt:118-131`
- **Что показывает:** при скорости ≥ 20 км/ч — л/100 км. Ниже 20 км/ч — л/ч с подписью «л/ч · стоянка». Строка под кольцом: «Мгновенный X л/ч».
- **Как считается:** заполнение кольца = `л/100 / 20` (полное кольцо = 20 л/100). Значения — `instPer100` и `instLh` (14.1).
- **Нормы / подсказки** (ориентир): EJ20 турбо — город 12–16, трасса 9–11 л/100 км. EJ25 атмосферный — город 11–13, трасса 8–10.

#### Запас хода — `FuelScreen.kt:135`
`rangeKm`, км (14.5).

#### Осталось топлива / Осталось (датчик) — `FuelScreen.kt:136-164`
- **Что показывает:** остаток, л; полосу и процент бака; строку «с заправки: X л» и, если ЭБУ отдаёт датчик уровня, «датчик Y В» или «Y Ом».
- **Источник:** если обучен датчик уровня — по датчику (подпись «(датчик)», раздел 14.4). Иначе подсчёт от последней заправки (14.3).
- **Как считается:** процент = `остаток / объём_бака`. «С заправки» = `usedSinceRefillL`.

#### Средний (поездка) / Средний (стоянка) — `FuelScreen.kt:165-169`
- **Как считается:** если у поездки нет л/100 (пробег ≤ 0,5 км) и она длится > 30 с, показывается `топливо / часы` в л/ч. Иначе `per100` поездки = `топливо / км · 100` (только при пробеге > 0,5 км, `Db.kt:28`).

#### Динамика расхода (график) — `FuelScreen.kt:187-245`
- **Что показывает:** столбики-область л/100 км по 10-секундным корзинам, агрегированным по шагу диапазона, и белый пунктир среднего за диапазон.
- **Диапазоны:** «10 мин» (шаг 10 с), «1 час» (шаг 1 мин), «Сегодня» (от местной полуночи, шаг 10 мин), «Неделя» (шаг 3 ч) (`FuelScreen.kt:187-192`).
- **Как считается:**
  - Точка = `топливо_шага / км_шага · 100`, ограничено сверху 30.
  - Точка рисуется, только если за шаг пройдено не меньше `max(min(шаг_ч · 10, 1), 0,02)` км (то есть ≥ 10 км/ч в среднем за шаг, но не больше 1 км). Иначе разрыв (стоянка или нет данных) (`FuelScreen.kt:208-213`).
  - Среднее = `Σтопливо / Σкм · 100`, если Σкм > 0,2 (`FuelScreen.kt:217`).
  - Обновление раз в 10 с.
- **Примечания:** в легенде линия названа «Мгновенный», но это среднее за шаг. Данные: корзины по 10 с, через 2 суток уплотняются до 10 мин, через 35 суток удаляются (14.10).

#### Информация о поездке — `FuelScreen.kt:249-279`
- **«В пути»** — ч:мин от начала поездки.
- **«Пробег»** — км (пробег считается по скорости ЭБУ с GPS-коррекцией, 14.6).
- **«Ср. скорость»** = `км / (длительность в часах)`, включая стоянки (`Db.kt:29`).
- **«Ср. расход»** — л/100 (при пробеге > 0,5 км) или л/ч (стоянка > 30 с).
- **«Топливо»** — л за поездку.
- **«Стоимость»** = `топливо · цена_за_литр`, текущая цена из настроек и валюта (`FuelScreen.kt:275`).
- **Кнопка «Сбросить»** закрывает текущую поездку (сохраняется, только если пробег > 0,05 км) и начинает новую, обнуляет счётчик откатов (`TripTracker.kt:174-181`).

#### Расход по режимам (кольцо) — `FuelScreen.kt:282-329`
- **Что показывает:** доли топлива и расход в режимах «Город», «Трасса», «Смешанный», «Стоянка».
- **Источник данных:** текущая поездка, если в ней больше 0,2 л, иначе все поездки (до 500).
- **Как считается:**
  - Классификация описана в 14.2.
  - Поездки, в которых в движении пройдено < 0,05 км, целиком считаются стоянкой (совместимость со старыми записями) (`FuelScreen.kt:288-294`).
  - Доля режима = `литры_режима / все_литры`.
  - Для Город/Трасса/Смешанный: `л/100 = л / км · 100`, при км > 0,3.
  - «Стоянка»: литры и `л/ч = литры / секунды · 3600`, если стоянка дольше 60 с.
  - В центре кольца: общий `л/100` (включая стоянку), если км > 0,3, иначе литры.
- **Цвета:** Город — фиолетовый, Трасса — синий, Смешанный — серый, Стоянка — оранжевый.
- **Примечания:** «Стоянка» включает и остановки внутри поездки (светофоры, пробки): всё, что сожжено при скорости < 2 км/ч.

#### Последние поездки — `FuelScreen.kt:347-384`
- **Что показывает:** 4 последние поездки: л/100 (или литры, если «стоянка» — пробег ≤ 0,5 км), «Сегодня/Вчера/дата · км · ч:мин».
- **Иконка:** парковка, если стоянка. «Трасса», если км трассы ≥ км города и ≥ км смешанного. «Город», если км города ≥ км смешанного. Иначе «маршрут» (`FuelScreen.kt:373-378`).

### 4.2 Вкладка «История» — `FuelScreen.kt:386-411`
- **Что показывает:** таблица за 30 дней по местным суткам: дата, пробег, топливо, л/100, стоимость.
- **Как считается:** корзины, суммированные по суткам. Показываются дни с км > 0,1 или топливом > 0,05 л. л/100 — при км > 0,5. Стоимость = `литры · текущая_цена`.

### 4.3 Вкладка «Заправки» — `FuelScreen.kt:414-513`

#### Новая заправка
- **Поля:** литры, цена за литр (необязательно, по умолчанию цена из настроек), флажок «Залил до полного».
- **Логика `RefillLogic.add`** (`FuelScreen.kt:477-513`):
  - Введённая цена становится ценой по умолчанию в настройках.
  - **Полный бак:**
    - факт = литры этой заправки + все неполные заправки после предыдущего полного бака;
    - расчёт = `usedSinceFullL` (сколько насчитано с предыдущего полного бака);
    - если полный бак уже отмечался раньше, расчёт ≥ 20 л и факт ≥ 15 л: `коэф = clamp(коэф · clamp(факт/расчёт, 0,8…1,25), 0,7…1,4)`;
    - иначе выводится подсказка без изменения коэффициента;
    - после этого `usedSinceFullL = 0`, «в баке» = объём бака (если задан).
  - **Неполная заправка:** в баке = `(было_при_заправке − израсходовано_с_заправки) + литры`, с ограничением объёмом бака. Если предыдущий уровень неизвестен, он считается нулевым.
  - В обоих случаях `usedSinceRefillL = 0`, запись сохраняется в журнал.
- **Внизу:** «Коэффициент расхода: X,XXX».

#### Таблица «Заправки»
Дата, литры, цена, сумма (`литры · цена`), полный (да/нет), «Расчёт, л» — сколько приложение насчитало с предыдущего полного бака на момент заправки.

### 4.4 Вкладка «Стиль вождения» — `FuelScreen.kt:516-545`
- **Что показывает:** текущую поездку, если она длится больше 60 с, иначе последнюю сохранённую.
- **Плитки:**
  - «Оценка»: `score = clamp(100 − (резкие_разгоны + резкие_торможения) · (3600 / max(длительность_с, 1800)) · 4 − доля_холостого_% · 0,3, 0…100)`. Поездки короче 30 минут считаются как 30-минутные.
  - «Резкие разгоны», «Резкие торможения» — пороги в 14.2.
  - «Холостой ход» = `время_с_мотором_при_скорости_<2 / длительность · 100` %.
  - «Макс. наддув» = `max(MAP − ATM) / 100` бар за поездку.
  - «Макс. обороты».
- **Нормы / подсказки:** 100 — ни одного резкого события и мало холостого хода. Каждое событие в пересчёте на час снимает 4 балла, каждый процент холостого — 0,3 балла.

### 4.5 Вкладка «Поездки» — `FuelScreen.kt:548-568`
- **Колонки:** начало, время, пробег, топливо, л/100, ср. скорость, «Город/Трасса» в процентах от пробега в движении (смешанный не показан). До 300 поездок.

## 5. АКПП (`ui/TransmissionScreen.kt`)
Экран скрыт, если в настройках выбрана механика. Подпись статуса внизу карточки гидротрансформатора: «АКПП: ожидание», «АКПП не отвечает», «АКПП: ROM …», «АКПП: демо».

### 5.1 Селектор / передача — `TransmissionScreen.kt:51-76`
- **Что показывает:** крупно — положение селектора (P/N, R, D, 3, 2, 1). Ниже — «Передача: N».
- **Источник:** TCU 0x6B (биты) и 0x4A (`x + 1`).
- **Как считается:** номер передачи показывается только в D/3/2/1, иначе «—».

### 5.2 Температура ATF — `TransmissionScreen.kt:116-139`
- **Что показывает:** кольцо и полоса 0…130 °C с подписью-оценкой.
- **Источник:** TCU 0x56 (`x − 50`) или 0x49 (таблица).
- **Пороги в приложении** (`TransmissionScreen.kt:117-123`):
  - < 40 °C — «холодная, не нагружайте» (синий);
  - 40…100 °C — «норма» (зелёный);
  - 101…115 °C — «горячая» (оранжевый);
  - > 115 °C — «перегрев!» (красный).
- **Нормы / подсказки:** в обычной езде 60–90 °C (ориентир). Затяжные подъёмы, прицеп и пробки поднимают температуру.

### 5.3 Гидротрансформатор — `TransmissionScreen.kt:78-88`
- **Что показывает:** «Заблокирован»/«Разблокирован», обороты двигателя, обороты турбины, проскальзывание, %.
- **Как считается:**
  - Заблокирован = `lock-up > 60 %` (`TransmissionScreen.kt:47`).
  - Проскальзывание = `(обороты_двигателя − обороты_турбины) · 100 / обороты_двигателя`, только при оборотах > 800 (`TransmissionScreen.kt:46`).
  - Подсвечивается оранжевым, если > 15 % **при заблокированном** трансформаторе (`TransmissionScreen.kt:85`).
- **Нормы / подсказки:** в блокировке проскальзывание близко к 0. Шаг оборотов турбины — 32 об/мин, поэтому ±1–3 % — шум. При разблокированном трансформаторе на разгоне большое проскальзывание нормально (ориентир).

### 5.4 Плитки — `TransmissionScreen.kt:91-94`

#### Блокировка (Lock-up)
- **Источник:** TCU 0x4C, `x/2` %.
- **Нормы / подсказки:** 0 — нет блокировки, около 90–100 — полная блокировка (ориентир по демо: 95).

#### Давление в линии
- **Источник:** TCU 0x4B, `x/2` %. Это скважность соленоида давления, а не давление в барах.

#### Муфта полного привода — `TransmissionScreen.kt:147-177`
- **Что показывает:** скважность муфты, %, и оценку распределения «≈ перед:зад β».
- **Источник:** TCU 0x4D, `x/2` %.
- **Как считается** (доля на заднюю ось, `TransmissionScreen.kt:151-154`):
  - MP-T: `зад = 50 · duty/100` (0 % → 100:0, 100 % → 50:50);
  - VTD: `зад = 55 − 5 · duty/100` (0 % → 45:55, 100 % → 50:50).
  - Схема выбирается в настройках, по умолчанию MP-T.
- **Предупреждение «передние буксуют»:** скорость задних колёс > 5 км/ч и передние быстрее задних больше чем на 3 км/ч (`TransmissionScreen.kt:155`).
- **Примечания:** «β» — оценка. В SSM нет прямого параметра распределения, предполагается линейная зависимость от скважности. Комментарий в коде говорит, что это ещё не проверено по логам (`TransmissionScreen.kt:141-145`).

#### Колёса перед / зад
TCU 0x48 / 0x51, км/ч.

### 5.5 Графики — `TransmissionScreen.kt:97-110`
- «Температура ATF, °C», 0…130.
- «Блокировка и полный привод, %», 0…100: lock-up (зелёная), AWD (синяя), «линия» (фиолетовая).
- Буфер 120 снимков АКПП, то есть 360 циклов ЭБУ.

## 6. АКБ (`ui/BatteryScreen.kt`)

### 6.1 Сейчас — `BatteryScreen.kt:81-96`
- **Что показывает:** текущее напряжение (2 знака), полосу 10…15 В (красный→оранжевый→зелёный) и строку «Заряд по напряжению покоя: N %».
- **Как считается:** степень заряженности = функция от **напряжения покоя** (не от текущего), `BatteryMonitor.kt:140-144`:
  - ≥ 12,7 В → 100 %;
  - ≤ 11,8 В → 0 %;
  - между ними `(В − 11,8) / 0,9 · 100`, линейно.
- **Примечания:** точность ограничена шагом ЭБУ 0,08 В.

### 6.2 Покой (зажигание, двигатель заглушен) — `BatteryScreen.kt:97`, `BatteryMonitor.kt:58-71`
- **Как считается:** пока обороты = 0, напряжения копятся в окно из последних 40 отсчётов. Когда отсчётов ≥ 20 (около 5 с), публикуется **медиана**. Первая медиана после включения зажигания пишется в журнал.
- **Пороги в приложении** (`BatteryScreen.kt:43-48`):
  - ≥ 12,5 В — «заряжен» (зелёный);
  - ≥ 12,2 В — «заряжен частично» (оранжевый);
  - ниже — «разряжен — нужна зарядка» (красный).
- **Нормы / подсказки:** мерить после стоянки, а не сразу после поездки, — иначе поверхностный заряд завышает значение.

### 6.3 Просадка при пуске — `BatteryScreen.kt:98-101`, `BatteryMonitor.kt:73-91`
- **Что показывает:** минимальное напряжение во время работы стартера и «запуск X,X с».
- **Как считается:**
  - Пуск = переход оборотов через 500, если мотор был заглушен (обороты = 0) в последние 10 с.
  - Минимум ищется среди отсчётов последних 4 с с оборотами < 500.
  - Длительность = от первого отсчёта, который ниже последнего напряжения покоя на 0,3 В, до момента «завёлся».
  - Записи с минимумом > 11,5 В при старте приложения удаляются как ложные (`Db.kt:78-80`).
- **Пороги в приложении** (`BatteryScreen.kt:50-55`):
  - ≥ 10,0 В — «отлично держит пуск» (зелёный);
  - ≥ 9,6 В — «норма» (оранжевый цвет);
  - ниже — «слабый — пора проверить/менять» (красный).

### 6.4 Заряд от генератора — `BatteryScreen.kt:102-108`, `BatteryMonitor.kt:93-106`
- **Что показывает:** среднее напряжение при работающем моторе и строку «мин / макс В, генератор N %».
- **Как считается:**
  - Через 30 с после пуска копятся отсчёты (до 600). Значение = их среднее.
  - Мин/макс — по всем отсчётам с момента запуска приложения.
  - После 60 отсчётов значение один раз пишется в журнал вместе со скважностью генератора 0x3A.
- **Пороги в приложении** (`BatteryScreen.kt:57-62`):
  - < 13,2 В — «недозаряд — проверьте генератор/ремень» (красный);
  - 13,2…14,8 В — «генератор в норме» (зелёный);
  - > 14,8 В — «перезаряд — проверьте регулятор» (красный).

### 6.5 Графики
- «Напряжение, последняя минута»: живой буфер ЭБУ, шкала 9…15 В (`BatteryScreen.kt:111-115`).
- «История напряжения» (24 часа / Неделя): средние значения из таблицы `volts`, которая пишется раз в минуту (`BatteryMonitor.kt:50-56`). Группировка по 10 мин (24 ч) или по 1 ч (неделя). Шкала 9…15 В, обновление раз в минуту (`BatteryScreen.kt:73-76`, `116-132`).

### 6.6 Журнал аккумулятора — `BatteryScreen.kt:134-157`
- 60 последних событий: «Покой», «Пуск (мин.)» с длительностью, «Заряд» с процентом генератора.
- Дублируется в `logs/battery.csv`, хранятся последние 5000 строк.

## 7. Ошибки (`ui/DtcScreen.kt`)

### 7.1 Левая панель
- **Переключатель «Двигатель / АКПП».**
- **Информация:** «Связь: есть/нет», SSM ID, ROM ID выбранного блока, «Кодов в таблице: N». В таблицах приложения 587 кодов ЭБУ (база RomRaider v370); для АКПП — 79 кодов (Subaru, 2-значные) или 88 (OBD-II).
- **Таблица для АКПП:** выбирается по биту 7 байта 37 init-ответа АКПП (`DtcScreen.kt:78-81`).
- **«Прочитать ошибки»** (`DtcScreen.kt:84-99`): читаются все байты состояния из таблицы, пачками по 30 адресов. Для каждого кода проверяется бит в байте «текущая» и в байте «в памяти». Байт 0xFF считается «адрес не реализован» и пропускается.
- **«Сбросить ошибки»:** запись 0x40 по адресу 0x000060 выбранного блока (`DtcScreen.kt:102`), после подтверждения. Сбрасывает также адаптации: топливные коррекции, обучение холостого хода и детонации. После сброса выключить зажигание на 5–10 с.
- **Статусы:** «Ошибок нет», «Найдено: N», «Не удалось прочитать (нет связи с ЭБУ)», «Таблица кодов ошибок не загружена».

- **Режим OBD-II** (когда ЭБУ не отвечает по SSM, см. 12.2): коды читаются стандартными командами 03 (подтверждённые: «Текущая» и «В памяти») и 07 (ожидающие: только «Текущая»), сброс — команда 04. Описание берётся из таблицы Subaru по совпадающему коду. Вкладка АКПП в этом режиме недоступна.

Код (оранжевый), описание на русском и английском, «Текущая» («да» красным), «В памяти».

## 7А. Датчики (`ui/SensorsScreen.kt`, `ssm/RomRaider.kt`)
Все параметры, которые умеет отдавать ЭБУ и АКПП этой машины, как в программах для ноутбука (RomRaider, EcuExplorer). Источник — встроенная база логгер-определений RomRaider v370 (romraider.com); в репозитории её собирает скрипт из папки tools/romraider.

- **Левая панель «Все параметры ЭБУ»:** список доступного для подключённого блока, фильтры «Все / Двигатель / АКПП / Переключатели / Расширенные» и поиск по русскому и английскому названию или по id (P8, E1…).
  - Стандартные параметры (245) и переключатели (172) показываются, если их бит возможностей стоит в init-ответе блока. Расчётные (например, P200 «Нагрузка двигателя (расчётная)») — если есть всё, из чего они считаются.
  - Расширенные параметры (204: IAM, коррекции по детонации FBKC/FLKC, целевой наддув, топливные таблицы…) — только для прошивок, которые есть в базе (605 ROM ID). Адрес у каждой прошивки свой.
  - Отметка параметра сохраняется в настройках (ключ `watch`) и действует при следующих подключениях.
- **Правая панель «Выбранные параметры»:** название, минимум, текущее значение, максимум, единицы. Минимум и максимум считаются, пока открыт экран; кнопка «Сбросить мин/макс». Переключатели показываются как «вкл/выкл». Если блок не отдаёт параметр, под названием пишется «ЭБУ не отдаёт этот параметр».
- **Как читается:** отмеченные параметры идут отдельным запросом A8 после основного опроса, чтобы незнакомый ЭБУ адрес не ломал основные приборы. Если блок три раза подряд не ответил, приложение проверяет параметры по одному и оставляет только отвечающие. Значение: байты (1, 2 или 4, big-endian; `float`, `int8/16/32` или беззнаковое) → бит, если параметр однобитный → формула RomRaider (`+ − × ÷`, скобки, ссылки на другие параметры вида `P12` и `[P9:kph]`).
- **CSV-лог:** отмеченные параметры добавляются в конец строки колонками вида `P90 IAM multiplier`. При изменении выбора начинается новый файл.
- На K-Line каждый адрес добавляет к циклу опроса около 15 мс; в режиме OBD-II и в демо-режиме список пуст.

## 7Б. Замеры
Включается в «Функции» → «Замеры разгона и круги».

### 7Б.1 Разгон
- **С места:** остановитесь полностью, карточка напишет «Готов». Время пойдёт с первого движения (момент, когда скорость прошла 0,5 км/ч).
  - Отсечки: 0–60, 0–100, 0–150, 0–200 км/ч, 201 м и 402 м с конечной скоростью.
  - Замер заканчивается, когда скорость падает на 4 км/ч от максимума (отпустили газ) или через 60 с.
- **С хода:** 60–100, 80–120, 100–200 км/ч. Считаются всегда, если скорость непрерывно росла от нижней границы до верхней.
- **Точность:** скорость берётся из ЭБУ с коэффициентом спидометра, выученным по GPS. Момент пересечения порога интерполируется между соседними замерами, путь — интеграл скорости. Ожидаемая точность ±0,1–0,2 с.
- **Сохранение:** последние 40 замеров с лучшими результатами по каждой отсечке. В демо-режиме замеры показываются, но не сохраняются.
- Разгон до сотни объявляется предупреждением.

### 7Б.2 Диностенд
- Пока педаль (или дроссель) открыта больше чем на 85 % на скорости от 10 км/ч, копятся точки «время, скорость, обороты».
- Мощность на колёсах = (m·a + ½·ρ·CdA·v² + 0,015·m·g)·v, где m — масса из настройки (по умолчанию 1550 кг), CdA = 0,85 м², a — наклон скорости за ±0,3 с.
- Точки группируются по 250 об/мин. Момент = мощность / (2π·об/мин/60). На коленвалу ≈ +15 %.
- Это оценка: сравнивайте свои замеры между собой на одной передаче, ровной дороге и в безветрие.

### 7Б.3 Круги
- Кнопка «Старт/финиш здесь» запоминает текущую точку GPS.
- Круг засчитывается в момент наибольшего приближения к точке (ближе 25 м) после того, как машина отъехала дальше 60 м.
- GPS магнитолы обновляется раз в секунду, точность около ±0,5 с. Лучший круг выделяется, каждый круг объявляется.

### 7Б.4 G-метр и крен
- **Акселерометр магнитолы**, если он есть. Его нужно обнулить, когда машина стоит на ровном месте: приложение запоминает направление «вниз» для этой установки.
  - Дальше крен и тангаж считаются из вектора тяжести, перегрузки — из остатка ускорения.
  - Продольная ось — «сквозь экран вперёд».
- **Без акселерометра:**
  - продольная перегрузка — наклон скорости ЭБУ за 0,8 с;
  - боковая — датчик VDC (параметр RomRaider P172, SH и новее) или скорость × поворот курса GPS;
  - крена нет.
- **Уклон дороги:** изменение высоты GPS на последних ~150 м, в %.
- Максимумы: боковая, разгон, торможение; кнопка сброса.

## 7В. Здоровье
Экран включается в «Функции» → «Экран „Здоровье“». Каждое предупреждение включается там же отдельно.

### 7В.1 Мотор
- **IAM и детонация.** IAM, FBKC и FLKC читаются дополнительным запросом, если адреса есть в базе RomRaider для этой прошивки. Для IAM подходят P90, E31, E96, E111 или E1; у 16-битных ЭБУ значение делится на 16.
  - Предупреждения: IAM ниже 0,75; падение IAM на 0,1 за поездку; FLKC до −2,8°; FBKC до −4° под наддувом.
  - История IAM: одно значение на поездку, если оно изменилось или прошла неделя. Рядом — последняя заправка перед поездкой.
- **Турботаймер** (только турбо: был наддув больше 15 кПа или в подписи машины turbo/STI/WRX/GT).
  - «Жар» 0…100 копится от наддува и высоких оборотов и остывает на холостых.
  - На холостых после нагрузки — обратный отсчёт «Турбина остывает: N с» в углу экрана. Затем «можно глушить».
- **Прогрев.** Масло берётся из ЭБУ (P122) или оценивается: догоняет ОЖ с постоянной времени ~7 минут. Пока масло ниже 60°, на оборотах выше 3600 будет предупреждение.
- **Термостат.** Время прогрева от холодного пуска (ОЖ ниже 45°) до 80°. Если за 20 минут движения ОЖ ниже 72° — предупреждение.
- **Охлаждение.** Перегрев от 105°. Рост ОЖ на 8° и больше за минуту, когда мотор был прогрет (80–98°): на EJ25 так проявляется прогар прокладки ГБЦ или воздушная пробка.
- **ATF:** предупреждение при 110°, тревога при 120°.

### 7В.2 ТО
- **Пробег** вводится один раз по одометру, дальше к нему прибавляется пробег поездок, которые насчитало приложение.
- **Пункты по умолчанию (EJ):**
  - масло — 7 500 км / 6 мес;
  - ремень ГРМ с роликами и помпой — 100 000 км / 6 лет;
  - свечи — 30 000 / 3 года;
  - воздушный фильтр — 30 000 / 2 года;
  - салонный фильтр — 15 000 / год;
  - ATF частично — 40 000 / 3 года (у МКПП масло — 45 000 / 4 года);
  - задний редуктор — 45 000 / 4 года;
  - антифриз — 40 000 / 3 года;
  - тормозная жидкость — 40 000 / 2 года;
  - приводные ремни — 40 000 / 3 года;
  - осмотр тормозов — 15 000 / год.
- Интервал, дата и пробег последней замены редактируются нажатием на пункт. Можно добавить свои пункты и выключить ненужные (например, ремень на цепных FB/FA).
- **Напоминание:** раз в день при поездке, если осталось меньше 500 км или 14 дней.

### 7В.3 Шины
- Нужны Bluetooth LE-датчики TPMS с данными производителя 0x0100: позиция 0x80–0x83, давление в Па, температура в 0,01 °C, заряд батареи.
- Позиция по умолчанию по номеру датчика (1 — переднее левое … 4 — заднее правое). Если перепутали — нажмите два колеса подряд, датчики поменяются местами.
- **Предупреждения:** давление ниже порога (по умолчанию 1,8 бар); медленная утечка — минус 0,15 бар за 5–10 минут.
- Нераспознанные датчики с «TPMS» в имени пишутся в журнал обмена.

### 7В.4 Предупреждения
Последние 50 предупреждений с временем. Предупреждение показывается баннером поверх любого экрана; обычные исчезают через 9 с, тревожные — по нажатию.

## 14. Фоновые расчёты (service/)

### 14.1 Мгновенный расход топлива — `service/TripTracker.kt:11-38`

Формула `FuelCalc.litersPerHour(s, k)`:
1. Если оборотов нет, MAF нет или обороты < 300 — 0.
2. **Отсечка топлива:** время впрыска < 0,2 мс при оборотах > 1100 — 0 (строка 25).
3. AFR по датчику (`λ · 14,7`).
   - **Замкнутая петля** — датчика нет или AFR в пределах 13,5…16,0:
     `топливо_г/с = MAF / 14,7 · (1 + clamp((коррекция_A/F + обучение_A/F) / 100, −0,35…+0,35))`.
   - **Обогащение / обеднение** — AFR вне 13,5…16,0:
     `топливо_г/с = MAF / clamp(AFR, 10…18,5)`. Коррекции здесь не учитываются, они уже отражены в фактическом AFR.
4. Результат умножается на коэффициент калибровки `k` (`fuelK`).
5. `л/ч = топливо_г/с · 3600 / 745`, где 745 г/л — плотность бензина (строка 12).

На экран идёт сглаженное значение: `lhShown += (lh − lhShown) · 0,3` на каждом отсчёте, примерно 1,5 с при ~4 Гц (`TripTracker.kt:150`). Поездки и корзины считаются по несглаженному значению.

`л/100 км = л/ч / скорость · 100`, только при скорости ≥ 20 км/ч; ниже — `null`, на экране показываются л/ч (`TripTracker.kt:246`). Скорость здесь — скорость ЭБУ с GPS-коррекцией.

Расход считается только при работающем моторе (обороты > 300) (`TripTracker.kt:83`, `93`).

### 14.2 Поездки и их классификация — `service/TripTracker.kt:78-201`
- **Начало поездки:** первый отсчёт с оборотами > 300 (`TripTracker.kt:97-103`). Сбрасывается счётчик откатов.
- **Конец:** через 2 минуты после последнего отсчёта с работающим мотором. Проверка идёт и при отсутствии связи с ЭБУ (`TripTracker.kt:156-171`). Поездка сохраняется, если пробег > 0,05 км **или** топливо > 0,02 л; иначе отбрасывается.
- **Шаг времени:** `dt = (t − t_пред) / 1000`, ограничен 0…2 с (`TripTracker.kt:81`).
- **Скорость** (`TripTracker.kt:87-91`): `скорость_ЭБУ · speedK`. Если ЭБУ скорость не отдаёт, берётся GPS при «свежем» фиксе (< 3 с, точность < 15 м), иначе 0.
- **Пробег** += `скорость · dt / 3600`; **топливо** += `л/ч · dt / 3600`.
- **«Движется»:** скорость ≥ 2 км/ч (`TripTracker.kt:110`).
- **Режим** определяется по **средней скорости за последние 2 минуты** — скользящее окно отсчётов, в том числе стоянок (`TripTracker.kt:107-109`):
  - Город — в движении и средняя < 45 км/ч;
  - Смешанный — в движении и 45 ≤ средняя < 75 км/ч;
  - Трасса — в движении и средняя ≥ 75 км/ч;
  - Стоянка — время, когда мотор работает, а скорость < 2 км/ч; топливо стоянки — всё топливо при скорости < 2 км/ч (`TripTracker.kt:122-129`).
- **Резкий разгон / торможение** (`TripTracker.kt:111-117`):
  - ускорение = `(скорость − скорость_пред) / 3,6 / dt`, м/с²;
  - резкий разгон — > 3,0 м/с² (примерно 0→100 км/ч быстрее 9,3 с);
  - резкое торможение — < −3,5 м/с²;
  - после любого события следующее засчитывается не раньше чем через 3 с.
- **Максимумы:** «макс. наддув» = max(`MAP − ATM`) кПа, «макс. обороты».
- **Сохранение:** каждые 30 с текущая поездка пишется в базу (upsert). Израсходованное топливо добавляется в счётчики «с заправки» и «с полного» тоже раз в 30 с — бережём флеш-память (`TripTracker.kt:139-141`, `148`, `190-201`).
- **Корзины для графиков:** 10-секундные суммы топлива и км (`TripTracker.kt:216-229`).
- После перезапуска сервиса начинается новая поездка, старая запись остаётся (`TripTracker.kt:61-64`).

### 14.3 Остаток топлива по заправкам
`остаток = clamp(fuelAtRefillL − usedSinceRefillL − ещё_не_сохранённое, ≥ 0)`. Если уровень при заправке неизвестен (−1), остаток не определён (`TripTracker.kt:233-234`). Уровень при заправке задаётся заправками (4.3) или полем «Сейчас в баке».

### 14.4 Датчик уровня топлива (только ЭБУ, которые его отдают; у SG его нет) — `service/FuelSensorCal.kt`
- Адреса 0x2E (В, `x/50`) или 0x10D (Ом, `x · 2`), опрашиваются, только если ЭБУ их заявил. Если есть оба, берутся омы.
- **Сглаживание:** `sm += (x − sm) · 0,03` на каждый отсчёт (`FuelSensorCal.kt:54`).
- **Обучение:** только на стоянке (скорость < 1 км/ч) и когда остаток известен по заправкам. Не чаще раза в 5 с сглаженное значение датчика попадает в одну из 50 ячеек: 0…5 В или 0…400 Ом. В ячейке копится среднее «литров по заправкам» (`FuelSensorCal.kt:56-61`). Ячейки сохраняются раз в минуту.
- **Когда начинает показывать по датчику** (`FuelSensorCal.kt:65-82`):
  - ячеек хотя бы с 6 отсчётами — не меньше 3;
  - их литры покрывают ≥ 35 % объёма бака (≥ 20 л, если объём 0).
  Тогда остаток = линейная интерполяция между ячейками, с ограничением 0…объём бака. На экране подпись «Осталось (датчик)».
- Смена единицы (В↔Ом, другой ЭБУ) сбрасывает обучение.

### 14.5 Запас хода — `service/TripTracker.kt:231-251`
`запас_км = остаток_л / средний_расход · 100`. Средний расход выбирается по порядку:
1. `л/100` текущей поездки, если в ней > 10 км;
2. иначе средний по всем поездкам, если суммарно > 20 км;
3. иначе 10 л/100 км.

### 14.6 Коррекция спидометра по GPS — `service/TripTracker.kt:203-214`
- **Условия:** GPS свежий (< 3 с, точность < 15 м); скорость ЭБУ ≥ 40 и скорость GPS ≥ 40 км/ч; езда ровная — скорректированная скорость ЭБУ отличается от предыдущего отсчёта не больше чем на 3 км/ч; отношение `GPS / ЭБУ` в пределах 0,85…1,15.
- **Обновление:** `speedK = speedK · 0,995 + отношение · 0,005` (экспоненциальное среднее), сохраняется раз в минуту.
- **Применяется:** к пробегу, расходу на 100 км, классификации, резким событиям. Стрелка спидометра и цифра скорости в компактном режиме показывают сырую скорость ЭБУ.
- Видно в Настройках → «Коррекция спидометра (GPS)».

### 14.7 Монитор АКБ — `service/BatteryMonitor.kt`
См. раздел 6. «Работает» = обороты > 500 (`BatteryMonitor.kt:44`). Минутные средние сохраняются в таблицу `volts` (`BatteryMonitor.kt:50-56`). После перезапуска последние значения покоя, пуска и заряда восстанавливаются из журнала (`BatteryMonitor.kt:110-121`).

### 14.8 Откаты зажигания (KnockWatch) — `service/KnockWatch.kt:30-40`
- **Начало события:** коррекция детонации ≤ −1° (`KnockStats.START_DEG`), если открытого события нет.
- **Пока событие идёт:** если коррекция стала глубже — обновляются максимум и снимок параметров в этот момент (обороты, нагрузка, дроссель, скорость, ОЖ, УОЗ).
- **Конец:** коррекция вернулась к ≥ 0 или мотор остановился (обороты < 300).
- **Сброс:** с каждой новой поездкой. Завершённые события дописываются в `logs/knock.csv` (последние 2000 строк). Демо-данные туда не пишутся.

### 14.9 Журналы CSV
- Подробный лог на каждый запуск двигателя (8.1).
- `battery.csv`: datetime, type, volts, extra (`BatteryMonitor.kt:123-136`).
- `knock.csv`: time, duration_s, max_pull_deg, rpm, load_g_rev, throttle_pct, speed_kmh, coolant_c, timing_deg.

### 14.10 Обслуживание хранилища (Housekeeping) — `service/Housekeeping.kt`
Запускается при старте сервиса, затем раз в час.
- Подробные CSV старше срока хранения (24/72/168 ч) удаляются. Если папка больше 200 МБ, удаляются самые старые файлы.
- `battery.csv` обрезается до 5000 строк, `knock.csv` — до 2000.
- 10-секундные корзины старше 2 суток уплотняются до 10 минут. Корзины и минутные напряжения старше 35 суток удаляются.
- Поездки, заправки и события АКБ хранятся всегда.

### 14.11 Голосовое управление (Voice) — `service/Voice.kt`
**Голосовых предупреждений (озвучки порогов) в приложении нет.** Синтеза речи нет: функция `say()` только показывает тост (`Voice.kt:245-247`). Звучит лишь короткий сигнал после имени без команды (`Voice.kt:249-251`).

Распознавание:
- Нужна фраза «<имя> <команда>». Имя сравнивается нечётко: расстояние Левенштейна ≤ max(1, длина/4) или совпадение первых 4 букв для слов от 5 букв (`Voice.kt:260-265`).
- Если сказано только имя: сигнал, «Слушаю…», затем 6 с на команду (`Voice.kt:169-174`).

Команды проверяются по порядку (`Voice.kt:185-207`), вхождение подстроки:
1. начинается с «поехали / маршрут / едем / проложи / найди» → поиск адреса в Яндекс Навигаторе;
2. название или голосовая фраза пользовательской кнопки → запуск этой кнопки;
3. «весь экран» / «на весь» → выход из разделённого экрана;
4. «громче» / «тише» → громкость ±2 шага;
5. «следующ / дальше / далее» → следующий трек (или пресет, если играет радио); «предыдущ / назад» → предыдущий;
6. «пауза / стоп» → пауза; «играй / продолж / включи музыку» → воспроизведение;
7. «радио» → включить радио и открыть «Медиа»;
8. «расход» → «Расход»; «коробк / акпп» → «АКПП» (игнорируется при механике); «аккумулятор / батаре» → «АКБ»; «ошибк» → «Ошибки»; «динамик / наддув» → «Динамика»; «главн / приборы» → «Главная»; «медиа / плеер» → «Медиа» (только FYT);
9. иначе «Не понял: …».

### 14.12 Уведомление сервиса — `service/EcuService.kt:493-500`
Постоянное уведомление «ЭБУ», текст раз в 5 с: «X л/100 км», когда скорость ≥ 20 км/ч, иначе «X л/ч».

## 16. Найденные ошибки и несоответствия

1. **Одинаковые заголовки у разных плиток — важно для новых «i»-подсказок.** `InfoButton` ищет текст по заголовку (`ui/Info.kt:37`).
   - Плитки `fuel` (л/ч) и `per100` (л/100) обе называются «Расход» (`HomeScreen.kt:158`, `168`): у них будет одна подсказка на два разных показателя.
   - «Абс. давление» на Главной — только MAP (`HomeScreen.kt:164`), а на «Динамике» — «MAP / ATM» (`DriveScreen.kt:95`).
   - Сам объект `InfoTexts.byTitle` пока пуст (`ui/InfoTexts.kt:5`), поэтому кнопки «i» не отображаются.
2. **Спидометр без GPS-коррекции.** Стрелка на Главной (`HomeScreen.kt:103`) и цифра в компактном режиме (`CompactScreen.kt:98`) показывают сырую `speedKmh`. Пробег, л/100 и классификация считаются по `speedKmh · speedK` (`TripTracker.kt:88`). Отображаемая скорость и пробег могут расходиться на несколько процентов.
3. **Разные пороги детонации.** На плитке Главной — при < −2° (`HomeScreen.kt:155`), в компактном режиме — при любом < 0 (`CompactScreen.kt:139`), в KnockWatch событие считается от ≤ −1° (`Knock.kt:28`).
4. **Разные шкалы ОЖ.** Нижняя панель: полоса `ОЖ / 110` от 0 (`MainActivity.kt:440`). Плитка: 40…110 (`HomeScreen.kt:146`). Компакт: `(ОЖ − 40) / 70`.
5. **Текст настроек противоречит коду.** «Уровень топлива ЭБУ не передаёт — остаток считается от последней заправки» (`LogSettingsScreens.kt:233-234`), хотя для ЭБУ с датчиком уровня есть `FuelSensorCal` и подпись «Осталось (датчик)».
6. **«Параметров опрашивается N из 23»** (`CarSetup.kt:202`). Если ЭБУ поддерживает необязательные адреса уровня топлива, их добавляют к списку (`EcuService.kt:377-378`), и может получиться «25 из 23».
7. **Демо и реальный режим по-разному переключаются на л/100.** В демо `instPer100` считается от 5 км/ч (`EcuService.kt:220`), в реальном режиме от 20 км/ч (`TripTracker.kt:246`).
8. **Топливо за последние ≤ 30 с не попадает в заправку.** `RefillLogic.add` (`FuelScreen.kt:481`, `508`) и «Сейчас в баке» (`LogSettingsScreens.kt:191`) обнуляют `usedSinceRefillL` / `usedSinceFullL`, но не трогают `pendingFuel` в `TripTracker` (`TripTracker.kt:67-74`). Литры, ещё не сброшенные в настройки, после заправки уйдут в счётчик нового бака, а в расчёт калибровки не попадут. Ошибка небольшая.
9. **Полный бак при объёме 0.** Если объём бака = 0, `fuelAtRefillL` не обновляется (`FuelScreen.kt:500`), а `usedSinceRefillL` обнуляется. Остаётся старое значение уровня, и остаток становится неверным.
10. **Сброс поездки теряет стоянку.** `resetTrip` сохраняет поездку, только если `distanceKm > 0.05` (`TripTracker.kt:175`), а обычное закрытие и периодическое сохранение — при пробеге > 0,05 **или** топливе > 0,02 л (`TripTracker.kt:159`, `194`). Ручной сброс стоянки или прогрева без пробега отбрасывает её, если до этого её не успели сохранить по 30-секундному таймеру.
11. **Ранний выход в `tick`.** При ошибке вставки в БД (`id < 0`) метод выходит до `flushBucket()` и `publish(0,0)` (`TripTracker.kt:164`). Последняя корзина и обнуление показаний откладываются.
12. **Мин/макс заряда за весь сеанс.** `chargingMinV` / `chargingMaxV` никогда не сбрасываются между запусками двигателя (`BatteryMonitor.kt:97-101`) и не восстанавливаются из журнала. Строка «мин/макс» на экране АКБ относится ко всему времени с запуска приложения, а не к текущей поездке.
13. **Длительность пуска может занижаться.** Точка отсчёта — `restingSamples.lastOrNull()` (`BatteryMonitor.kt:83`). Если ЭБУ во время прокрутки стартером отдаёт 0 об/мин (так предполагает комментарий в строке 78), последний «покойный» отсчёт уже является просадкой. Тогда порог «на 0,3 В ниже» почти не достигается, и «запуск X с» получается 0 или меньше реального. Надёжнее медиана или напряжение до начала просадки (требует проверки на машине).
14. **Цвет не совпадает со смыслом.** Вердикт «норма» при пуске 9,6–10,0 В окрашен оранжевым, как предупреждение (`BatteryScreen.kt:53`).
15. **Подпись графика «Мгновенный»** (`FuelScreen.kt:236`): на самом деле это среднее л/100 за шаг диапазона (10 с … 3 ч).
16. **Стоимость по текущей цене.** «Стоимость» в поездке и истории считается по текущей цене из настроек (`FuelScreen.kt:275`, `404`), а не по цене на день поездки. Кроме того, ввод цены при заправке перезаписывает цену в настройках (`FuelScreen.kt:480`).
17. **Средний расход за весь период** (`FuelScreen.kt:83`) включает топливо поездок-стоянок без пробега. Прогревы завышают средний л/100 и, через `publish`, влияют на запас хода (`TripTracker.kt:239`).
18. **Ограничение `dt ≤ 2 с`** (`TripTracker.kt:81`). С ELM327 опрос 23 адресов по одному плюс АКПП может занимать больше 2 с на цикл. Тогда пробег и топливо будут занижены (требует проверки на реальном адаптере).
19. **«Последняя минута» на графиках** — это 240 снимков (`EcuService.kt:348`). Минута получается только при ~4 Гц, с ELM327 окно длиннее (`BatteryScreen.kt:112`, комментарий `Repo.kt:249`).
20. **Сглаживание датчика уровня зависит от частоты опроса.** Коэффициент 0,03 на отсчёт (`FuelSensorCal.kt:54`) — это ~33 отсчёта, то есть ~8 с при 4 Гц. Комментарий обещает «~30 s», что верно только около 1 Гц.
21. **Резкие события на GPS.** Без скорости ЭБУ резкие события считаются по скорости GPS (`TripTracker.kt:89`). Её скачки могут давать ложные «резкие разгоны/торможения». Шум скорости ЭБУ (шаг 1 км/ч) при 0,25 с даёт до 1,1 м/с² — ниже порога.
22. **Неполная таблица режимов во вкладке «Поездки».** Колонка «Город/Трасса» (`FuelScreen.kt:562`) не показывает смешанный режим, поэтому сумма меньше 100 %.
23. **Спутники.** Количество берётся из `extras["satellites"]` (`EcuService.kt:443`), на новых Android это поле часто пустое. Плитка GPS будет показывать «спутников 0» при нормальном приёме.
24. **Высота GPS.** Для высоты используется `Location.altitude` — над эллипсоидом WGS-84 (`MainActivity.kt:443`, `EcuService.kt:441`). На экране это подано как просто «Высота», без поправки на геоид.
