# Двигатель EJ20 / EJ25: база правил для анализатора

Область: Subaru EJ20 (EJ201, EJ202, EJ204, EJ205, EJ207, EJ20 turbo JDM) и EJ25 (EJ251, EJ253, EJ255, EJ257),
атмосферные и турбо, JDM / EDM / USDM, Forester SG/SH, Impreza GD/GG/GC, Legacy BE/BH/BL/BP, 1999-2010.

Назначение: набор правил, которые анализатор применяет к живым данным и к поездкам. LLM потом только
пересказывает найденное, поэтому каждое правило здесь имеет числа, контекст, уровень, источник и оценку
уверенности. Тексты для водителя написаны простым русским без жаргона и без длинных тире.

Обозначения уверенности: **high** = заводской мануал Subaru или прямое описание логики ЭБУ (RomRaider
дизассемблер, Cobb); **medium** = согласуются несколько тюнинговых/форумных источников; **low** = единичные
источники или наш вывод из физики, требует проверки на реальных логах.

---

## 0. Соглашения для программиста

### 0.1 Производные величины

| Имя | Формула | Примечание |
|---|---|---|
| `load` (г/об) | `mafGs * 60 / rpm` | при rpm < 400 не считать |
| `injDutyPct` | `injPwMs * rpm / 1200` | 4-тактный, одна форсунка на цилиндр; при отсечке = 0 |
| `boostKpa` | `mapKpa - atmKpa` | относительный наддув; у приложения это `gaugeKpa` |
| `mapRatio` | `mapKpa / atmKpa` | для правил холостого хода, не зависит от высоты |
| `afTotal` | `afCorrPct + afLearnPct` | суммарная топливная коррекция |
| `iamN` | `IAM > 1.5 ? IAM/16 : IAM` | 16-битные ЭБУ (02-05 WRX и др.) дают 0..16, 32-битные 0..1 |
| `ambientEst` | `intakeC` в момент пуска после стоянки ≥ 6 ч | замена датчика наружной температуры |

### 0.2 Контексты (предикаты)

```
RUNNING     = rpm > 400
WARM        = coolantC >= 75 && minutesSinceStart >= 5
HOT_IDLE    = WARM && coolantC >= 80              // заводские значения "на холостом" сняты после прогрева
IDLE        = RUNNING && speedKmh == 0 && throttlePct < 3 && rpm < 1200, держится >= 20 с
CRUISE      = WARM && speedKmh >= 40 && |d(speedKmh)/dt| < 1 км/ч/с && throttlePct in 5..40, держится >= 10 с
CLOSED_LOOP = WARM && mafGs < 50 && throttlePct < 60 && injPwMs > 0.5 && !DECEL
              && afCorrPct меняется (не ровно 0.0 более 5 с)
              // граница open/closed loop на стоковых прошивках около 50-65 г/с (RomRaider)
DECEL       = throttlePct < 1 && rpm > 1300 && speedKmh > 10       // топливо отсекается, AFR около 20
WOT         = throttlePct >= 90 (или pedalPct >= 90), держится >= 1 с
PULL        = WOT && rpm растет && нет переключения передачи (rpm не падает > 300 за 0.3 с)
BOOST       = boostKpa > 20
TRANSIENT   = |d(throttlePct)/dt| > 30 %/с в последние 1.5 с, или переключение передачи в последние 1.5 с
AFTER_RESET = (все afLearn A/B/C/D == 0.0 и iamN < 1.0) или пользователь отметил сброс/снятие клеммы;
              окно действует до iamN >= 0.95 или 300 км
TURBO       = наддув > 20 кПа виден хотя бы раз, или модель из списка турбо
```

### 0.3 Общие правила подавления ложных тревог

1. **После сброса ЭБУ** (снятие клеммы, перепрошивка) IAM стартует с начального значения таблицы
   "Advance Multiplier (Initial)" (часто 8/16 = 0.5) и растет по мере езды; таблица FLKC пустая, A/F learning
   по нулям ([RomRaider t1840][rr1840], [форум про IAM=8 после сброса][iam8]). В окне `AFTER_RESET` все правила по
   низкому IAM переводятся в `info`.
2. **Ниже 60 °C ОЖ** ЭБУ не учит IAM и FLKC (условие "Coolant temp > 140F" в логике) ([RomRaider t1840][rr1840]).
3. **Шум датчика детонации** при нагрузке < 0.75-1.0 г/об и rpm < 3000 считается нормой даже на стоке
   ([RomRaider t6156][rr6156]). Такие события не поднимать выше `info`.
4. **FBKC на переходах** (резкий газ, сброс газа, переключение) почти неизбежен ([RomRaider t6156][rr6156],
   [RomRaider t8361][rr8361]). Исключать `TRANSIENT`.
5. **Параметры читаются не одновременно**, строка лога может отставать на сотни оборотов
   ([RomRaider t6156][rr6156]). Для условий "в одной точке" брать окно ±0.5 с.
6. **Высота.** Пользователи в горах (Бишкек около 800 м, перевалы 3000+ м): все пороги по давлению считать через
   `mapRatio` и `boostKpa`, а не через абсолютное `mapKpa`. Заводской диапазон `atmKpa`, который ЭБУ считает
   правдоподобным при выключенном моторе: 73.3-106.6 кПа ([FSM 2005 Impreza H4DOTC][fsm_wrx05]).

### 1.4 Как ЭБУ реагирует на детонацию (нужно для правильных правил)

Формула (16-бит ЭБУ, 32-бит в целом так же): `Total timing = Base + (Timing Advance Max * IAM/16) + FBKC + FLKC + компенсации`
([RomRaider t1840][rr1840], [Cobb Accesstuner][cobb_at]).

- **FBKC**: мгновенный откат примерно -2° за шаг (в логах часто -2.1), предел около -11°, возврат шагами около +1° /
  +0.35° за секунды. Работает в своем диапазоне rpm/нагрузки ([RomRaider t1840][rr1840], [t6156][rr6156]).
- **FLKC**: выученная поправка в ячейке 8x8 (rpm x нагрузка), шаг вниз около -1° (по умолчанию в логах -1.4),
  вверх +0.35°, предел около -12°. Значение "хуже одного шага" значит: сняли угол, а детонация повторилась
  ([RomRaider t6156][rr6156], [Cobb Accesstuner][cobb_at]: "любая поправка больше одного шага почти наверняка реальная проблема").
- **IAM**: грубая поправка всей таблицы. Если в ячейке FLKC накопилось больше 3.9° по модулю, ЭБУ переходит в
  режим грубой коррекции: IAM ставится в начальное значение, таблица FLKC стирается, IAM учится заново шагами 4/16
  ([RomRaider t1840][rr1840]). Отсюда практический порог: **FLKC ≤ -4° = почти гарантированное падение IAM**.
- IAM ниже максимума "почти всегда признак нездорового мотора или плохого бензина" ([RomRaider t6156][rr6156]),
  но владельцы стоковых машин видят IAM < 1.0 на плохом топливе ([SubaruOutback NA IAM][sso_iam]).
- На турбо низкий IAM может отключить управление наддувом ("BOOST CONTROL DISABLE (IAM)"): наддув падает до
  пружины ([24subaru wiki][wiki24_boost]).

## 2. Правила

Формат: id, название, параметры, условие, уровень, что сказать водителю, причины (по убыванию вероятности),
что проверить (сначала дешевое), применимость, источники, уверенность.

### Группа K: детонация и угол

#### K01 `iam_below_max`
- **Название:** IAM ниже максимума
- **Параметры:** IAM, coolantC, rpm
- **Условие:** `RUNNING && WARM && !AFTER_RESET && iamN < 0.95` держится всю поездку (или ≥ 10 мин)
- **Уровень:** warn
- **Водителю:** "ЭБУ уменьшил угол зажигания на всех режимах, потому что раньше слышал детонацию. Мотор
  тянет хуже и расходует больше. Чаще всего помогает хороший бензин."
- **Причины:** 1) бензин с низким октановым числом или плохого качества; 2) нагар в камерах, перегрев впуска;
  3) бедная смесь под нагрузкой (подсос, слабый насос); 4) ложная детонация (стук датчика, разболтанные экраны,
  поршневой стук на EJ25 SOHC); 5) неудачная прошивка.
- **Проверить:** заправиться на другой АЗС (турбо: 98, NA: 95), посмотреть FLKC и FBKC, топливные коррекции,
  свечи; сбросить ЭБУ и проехать 50-100 км.
- **Применимость:** все EJ с поддержкой IAM в RomRaider. NA на АИ-92 может держать IAM < 1 годами (low риск).
- **Источники:** [RomRaider t6156][rr6156], [RomRaider t1840][rr1840], [SubaruOutback NA IAM][sso_iam]
- **Уверенность:** high (механизм), medium (порог 0.95)

#### K02 `iam_low_danger` (уточнение существующего)
- **Параметры:** IAM
- **Условие:** `iamN < 0.75 && !AFTER_RESET && WARM`. Если `AFTER_RESET` и IAM растет: только `info`.
- **Уровень:** danger (turbo), warn (NA)
- **Водителю:** "Угол зажигания сильно урезан из-за детонации. Не давите газ в пол и не грузите мотор, пока не
  заправитесь хорошим бензином и показатель не восстановится."
- **Причины / проверить:** как K01; для турбо дополнительно бедная смесь под наддувом, перегрев впуска,
  перенаддув.
- **Применимость:** все; для турбо риск прогара поршней (ringland EJ255/EJ257).
- **Источники:** [RomRaider t6156][rr6156], [NASIOC ringland][nasioc_ring], [Subimods ringland][subimods_ring]
- **Уверенность:** high
- **Разногласие:** существующее правило срабатывает и сразу после сброса ЭБУ, когда IAM законно равен 0.5.
  Нужна проверка `AFTER_RESET`.

#### K03 `iam_drop_trip` (уточнение существующего)
- **Условие:** `iamStart - iamN >= 0.1` за поездку, при `!AFTER_RESET`. Дополнительно: если последняя заправка была
  в пределах 80 км (скачок уровня топлива), добавить причину "бензин".
- **Уровень:** warn
- **Водителю:** "За эту поездку ЭБУ снизил угол зажигания: была детонация. Если вы недавно заправились, скорее
  всего дело в бензине."
- **Источники:** [RomRaider t1840][rr1840], [drive2: пропал наддув после заправки][d2_fuel]
- **Уверенность:** high

#### K04 `iam_relearn_info`
- **Название:** ЭБУ заново учит угол после сброса
- **Условие:** `AFTER_RESET && iamN in [0.45..0.8]` и IAM растет в течение поездки
- **Уровень:** info
- **Водителю:** "После сброса ЭБУ заново подбирает угол зажигания. Это нормально. Первые 50-100 км поездите
  спокойно, без полного газа на холодном моторе."
- **Применимость:** все EJ с RomRaider IAM
- **Источники:** [RomRaider t1840][rr1840], [IAM=8 после сброса][iam8]
- **Уверенность:** high (механизм), medium (стартовое значение зависит от ROM)

#### K05 `flkc_beyond_one_step`
- **Название:** Выученная поправка больше одного шага
- **Параметры:** FLKC, load, rpm
- **Условие:** `WARM && load >= 1.0 && FLKC <= -(stepRom + 0.3)` где `stepRom` = 1.4 по умолчанию (бывает 1.0-2.1)
- **Уровень:** info при NA и load < 1.2; warn для турбо
- **Водителю:** "ЭБУ уже снимал угол на этом режиме, а детонация повторилась. Проверьте бензин и не крутите мотор
  в натяг на этой передаче."
- **Причины:** топливо, перегрев впуска, бедная смесь под нагрузкой, нагар, прошивка.
- **Источники:** [RomRaider t6156][rr6156], [Cobb Accesstuner][cobb_at]
- **Уверенность:** high

#### K06 `flkc_deep` (уточнение существующего -2.8)
- **Условие:** `FLKC <= -2.8` (warn, существующее, совпадает с границей нормы Cobb для EJ);
  `FLKC <= -4.0 && load >= 1.0` (danger: дальше ЭБУ сбрасывает IAM)
- **Водителю (danger):** "Мотор устойчиво детонирует под нагрузкой, ЭБУ снял больше 4 градусов. Снизьте нагрузку
  и заправьтесь хорошим бензином. Если повторится, нужна диагностика."
- **Источники:** [Cobb Datalog][cobb_dl], [RomRaider t1840][rr1840]
- **Уверенность:** high
- **Разногласие:** Cobb считает 0..-2.8 допустимым, RomRaider считает поводом разбираться все, что хуже -1.4.
  Предлагаемая лестница: -1.4 info, -2.8 warn, -4.0 danger.

#### K07 `knock_low_load_noise` (анти-правило)
- **Условие:** FBKC или FLKC < 0 при `load < 0.75 && rpm < 3000`
- **Уровень:** info, без баннера; только счетчик для трендов
- **Водителю:** не показывать. В отчете: "Мелкие срабатывания датчика детонации на малой нагрузке встречаются и
  на исправных моторах."
- **Источники:** [RomRaider t6156][rr6156]
- **Уверенность:** high

#### K08 `fbkc_transient` (анти-правило)
- **Условие:** FBKC < 0 и `TRANSIENT`
- **Уровень:** не тревожить; считать в тренд
- **Источники:** [RomRaider t6156][rr6156], [RomRaider t8361][rr8361]
- **Уверенность:** high

#### K09 `fbkc_mid_pull`
- **Название:** Откат зажигания в середине разгона
- **Параметры:** FBKC, throttlePct, rpm, load, boostKpa
- **Условие:** `PULL && !TRANSIENT && FBKC <= -2.0 && load >= 1.0`. Повтор в ≥ 2 разгонах в той же зоне rpm ±500
  повышает уровень.
- **Уровень:** warn (одиночный), danger (повтор на турбо под наддувом > 0.5 бар)
- **Водителю:** "Во время разгона мотор детонировал, ЭБУ убрал угол. Если повторяется на одних и тех же оборотах,
  не разгоняйтесь в пол до проверки бензина и смеси."
- **Причины:** топливо, бедная смесь на полном газу, горячий впуск, перенаддув, прошивка.
- **Проверить:** бензин, IAT, наддув против цели, свечи (калильное число после тюнинга).
- **Применимость:** все, критичнее турбо EJ255/EJ257 (прогар перемычек поршня, чаще 4-й цилиндр)
- **Источники:** [RomRaider t6156][rr6156], [NASIOC ringland][nasioc_ring], [Crawford ringland][crawford_ring]
- **Уверенность:** high (механизм), medium (порог)

#### K10 `fbkc_boost_strong` (уточнение существующего -4)
- **Условие:** `BOOST && boostKpa > 20 && FBKC <= -4` (warn, как сейчас); `FBKC <= -6` или 3 события за поездку
  (danger)
- **Источники:** [RomRaider t1840][rr1840]: шаг около 2°, значит -4 = два подряд срабатывания
- **Уверенность:** medium

#### K11 `knock_hot_intake`
- **Название:** Детонация на горячем впуске
- **Условие:** любое из K05/K06/K09 и `intakeC >= 50` (турбо) или `intakeC - ambientEst >= 35`
- **Уровень:** добавочная причина к сработавшему правилу
- **Водителю:** "Воздух во впуске очень горячий, от этого мотор склонен к детонации. Дайте машине проехать
  спокойно, чтобы интеркулер остыл."
- **Причины:** пробки и жара, стоянка с работающим мотором, интеркулер забит грязью или листвой.
- **Источники:** [FSM WRX 2005: IAT минус наружная не больше +50][fsm_wrx05], [RomRaider t6156][rr6156] (горячий впуск при перенаддуве)
- **Уверенность:** medium

#### K12 `knock_lean_wot` (турбо)
- **Условие:** `PULL && boostKpa > 50 && lambda > 0.85` (AFR > 12.5) держится ≥ 0.5 с
- **Уровень:** danger
- **Водителю:** "Под наддувом смесь бедная. Это опасно для поршней. Не давите газ в пол до проверки
  топливной системы."
- **Причины:** слабый бензонасос, забитый фильтр, утечка наддува после MAF с некорректным пересчетом, грязный MAF,
  неудачная прошивка.
- **Проверить:** давление топлива (заводское 284-314 кПа без вакуума), afLearn D, injDutyPct.
- **Применимость:** только турбо. Штатный датчик под наддувом неточен и в богатую сторону упирается около 11.1,
  поэтому бедное показание заслуживает внимания, а богатое ничего не доказывает.
- **Источники:** [RomRaider t6156][rr6156], [FSM WRX 2005][fsm_wrx05], [8020 EJ255][a8020]
- **Уверенность:** low-medium (точность штатного датчика)

#### K13 `knock_cold`
- **Условие:** FBKC < 0 при `coolantC < 60`
- **Уровень:** info, без баннера
- **Водителю (в отчете):** "На холодном моторе датчик детонации может слышать стук поршней. Пока мотор не
  прогрет, ЭБУ угол не учит."
- **Применимость:** EJ25 SOHC (EJ251/EJ253) склонен к поршневому стуку на холодную
- **Источники:** [RomRaider t1840][rr1840], [TTAC piston slap][ttac_slap], [RomRaider t8361][rr8361]
- **Уверенность:** medium

#### K14 `boost_cut_by_iam` (турбо)
- **Условие:** `PULL && rpm in 3500..5500 && boostPeak < 0.6 * baselineBoostPeak && iamN < 0.75`
- **Уровень:** warn
- **Водителю:** "Наддув снижен не из-за поломки турбины, а потому что ЭБУ защищает мотор после детонации.
  Заправьтесь хорошим бензином, через несколько поездок наддув вернется."
- **Источники:** [24subaru wiki][wiki24_boost], [drive2: наддув 0.5 вместо 1 бара после АЗС][d2_fuel]
- **Уверенность:** medium (порог IAM для отключения наддува зависит от ROM)

### Группа F: топливные коррекции и смесь

Коррекции оценивать только в `CLOSED_LOOP`, усредняя за ≥ 60 с. Одиночные значения afCorrPct до ±25 нормальны
([IWSTI][iwsti_corr], [Cobb Datalog][cobb_dl]).

#### F01 `trim_total_lean`
- **Параметры:** afCorrPct, afLearnPct, mafGs
- **Условие:** `CLOSED_LOOP && mean(afTotal, 120 с) >= +15` (warn) или `afLearnPct >= +14.5` (warn, коррекция в
  упоре) или `mean(afTotal) >= +25` (danger)
- **Водителю:** "ЭБУ постоянно добавляет топливо: в мотор попадает лишний воздух или не хватает бензина. Скоро
  может загореться Check Engine с ошибкой бедной смеси."
- **Причины:** 1) подсос воздуха после MAF (гофра впуска, шланги PCV, вакуумный шланг усилителя тормозов);
  2) грязный MAF (занижает расход); 3) слабый бензонасос / фильтр / регулятор; 4) утечка выхлопа до лямбда-зонда.
- **Проверить:** гофру между MAF и дросселем, хомуты, шланги PCV; почистить MAF спецочистителем; давление топлива.
- **Применимость:** все
- **Источники:** [RomRaider t4899][rr4899] (±15 = упор), [Cobb Datalog][cobb_dl], [go-parts P0101][gp_p0101],
  [FSM WRX 2005 P0171/P0172][fsm_wrx05]
- **Уверенность:** high (направление), medium (пороги)
- **Разногласие:** Cobb считает нормой learning ±10, RomRaider идеалом ±5, заводская таблица допускает ±15 на ХХ.
  Порог Subaru для P0171 в открытых источниках не найден.

#### F02 `trim_total_rich`
- **Условие:** зеркально F01: `mean(afTotal) <= -15` (warn), `afLearnPct <= -14.5` или `mean(afTotal) <= -25` (danger)
- **Водителю:** "ЭБУ постоянно убирает топливо, смесь слишком богатая. Растет расход и страдает катализатор."
- **Причины:** 1) клапан продувки адсорбера открыт постоянно (особенно сразу после заправки); 2) подтекающая
  форсунка; 3) высокое давление топлива (регулятор, снят вакуумный шланг регулятора); 4) MAF завышает (масляный
  фильтр нулевого сопротивления); 5) бензин в масле после коротких зимних поездок.
- **Источники:** [FSM WRX 2005: процедура P0172][fsm_wrx05], [RomRaider t4899][rr4899]
- **Уверенность:** medium

#### F03 `trim_idle_only_lean` (подсос)
- **Параметры:** A/F Learning #1 A, C (расширенные), либо afTotal на `IDLE` против `CRUISE`
- **Условие:** `learnA - learnC >= 8` или `mean(afTotal | IDLE) - mean(afTotal | CRUISE) >= 8`
- **Уровень:** warn
- **Водителю:** "На холостых ЭБУ добавляет заметно больше топлива, чем в движении. Так обычно проявляется
  подсос воздуха: трещина в гофре или шланге."
- **Причины:** подсос воздуха (на малом расходе воздуха он заметнее всего), утечка выхлопа перед датчиком
  (на турбо прокладки апайпа), клапан PCV.
- **Проверить:** гофра впуска, шланги PCV и вакуума, прокладки коллектора / апайпа, тест дымом.
- **Источники:** [RomRaider t2368][rr2368] (утечка выхлопа дает плюс на ХХ), [RomRaider t4899][rr4899]
  (диапазоны A: 0-5 г/с, B: 5-10, C: 10-40, D: 40+)
- **Уверенность:** medium-high

#### F04 `trim_lean_rising_with_load`
- **Условие:** `learnA, learnB, learnC, learnD >= +7` и `learnD >= learnC >= learnA`
- **Уровень:** warn
- **Водителю:** "Нехватка топлива растет вместе с нагрузкой. Похоже на слабый бензонасос или забитый фильтр."
- **Причины:** бензонасос, фильтр, регулятор давления, грязный MAF (занижает на больших расходах).
- **Проверить:** давление топлива на ХХ и с отключенным вакуумом регулятора (заводское 206-235 / 284-314 кПа).
- **Источники:** [FSM WRX 2005][fsm_wrx05], [RomRaider t4899][rr4899]
- **Уверенность:** medium

#### F05 `trim_rich_idle_purge`
- **Условие:** `learnA <= -8` при `|learnC| < 4`, или `mean(afCorrPct | IDLE) <= -12` в первые 15 мин после заправки
- **Уровень:** info / warn если держится 3 поездки
- **Водителю:** "На холостых смесь богатая, особенно после заправки. Часто виноват клапан продувки
  бензобака."
- **Причины:** клапан продувки (purge, CPC), подтекающая форсунка, высокое давление топлива на ХХ.
- **Источники:** [FSM LGT 2005: CPC duty на ХХ 0-25 %][fsm_lgt05], [FSM H4SO: 0-3 %][fsm_h4so]
- **Уверенность:** low-medium

#### F06 `fuel_dilution_short_trips`
- **Условие:** ≥ 4 поездки подряд с `max(coolantC) < 70`, после них `mean(afLearnPct | IDLE, CRUISE)` сдвинулся
  на ≤ -5 относительно базовой линии, и вернулся после длинной поездки
- **Уровень:** info
- **Водителю:** "Короткие поездки зимой: мотор не успевает прогреться, бензин и влага попадают в масло. Раз в
  неделю проезжайте 20-30 минут без остановок и меняйте масло почаще."
- **Причины:** испарение бензина из масла через PCV после прогрева
- **Применимость:** все; особенно важно для EJ25/EJ204 с историей залегания колец
- **Источники:** [drive2 SG: жор масла][d2_oil_sg], [drive2 SH раскоксовка][d2_oil_sh] (связь с залеганием колец), физика PCV
- **Уверенность:** low

#### F07 `af_correction_frozen`
- **Условие:** `WARM && speedKmh меняется && throttlePct in 5..40 && afCorrPct == 0.0 ровно` дольше 60 с
- **Уровень:** warn
- **Водителю:** "ЭБУ не использует датчик состава смеси и работает вслепую. Обычно это неисправность датчика
  или его подогрева. Расход может вырасти."
- **Причины:** подогрев переднего A/F датчика (P0031/P0032, предохранитель), сам датчик, режим аварии из-за
  другой ошибки.
- **Проверить:** коды ошибок, предохранитель подогрева, сопротивление подогрева (около 2-4 Ом по вторичным источникам).
- **Источники:** [go-parts P0031 Forester][gp_p0031], [Cobb Datalog][cobb_dl] (коррекция 0 только на полном газу и
  при сбросе)
- **Уверенность:** medium

#### F08 `af_correction_railed`
- **Условие:** `CLOSED_LOOP && |afCorrPct| >= 24` дольше 10 с
- **Уровень:** warn
- **Водителю:** "Смесь резко ушла из нормы прямо сейчас. Если мотор троит или глохнет, проверьте, не слетела ли
  гофра воздушного фильтра."
- **Причины:** слетел патрубок, оборвался вакуумный шланг, отказ датчика
- **Источники:** [IWSTI: correction > ±25][iwsti_corr]
- **Уверенность:** medium

#### F09 `lambda_lazy`
- **Условие:** `CLOSED_LOOP`, 60 с: `stdev(lambda) < 0.005` при `stdev(afCorrPct) > 3`
- **Уровень:** info
- **Водителю:** "Датчик состава смеси реагирует вяло. Он еще работает, но со временем может потребовать замены."
- **Источники:** общая логика замкнутого контура; [FSM: lambda 1.0 на ХХ][fsm_lgt05]
- **Уверенность:** low

#### F10 `decel_not_lean`
- **Условие:** `DECEL` ≥ 2 с и `lambda < 1.2` (AFR < 17.5)
- **Уровень:** info
- **Водителю:** "При сбросе газа топливо должно отключаться, а датчик показывает обычную смесь. Возможно,
  подтекает форсунка или датчик неисправен."
- **Источники:** [RomRaider t6156][rr6156] (при сбросе AFR около 20)
- **Уверенность:** low

### Группа A: воздух, MAF, MAP

#### A01 `idle_maf_range`
- **Условие:** `HOT_IDLE` 60 с, `mafGs < 1.8` или `mafGs > 5.5` (NA EJ25 верх 6.0)
- **Уровень:** info, warn если вместе с F01/F02
- **Водителю:** "Расход воздуха на холостых вне привычного диапазона. Если вместе с этим скачут коррекции,
  почистите датчик расхода воздуха."
- **Причины:** низкий: подсос после MAF, грязный MAF; высокий: нагрузка (кондиционер, генератор), MAF
  завышает, неверная прошивка (тюнинговая трубка MAF).
- **Источники:** [FSM][fsm_lgt05] 2.1-3.1, [FSM H4SO][fsm_h4so] 2.5, [RomRaider t6156][rr6156] "около 3; 5 г/с на ХХ
  значит ошибка калибровки MAF", [SubaruOutback MAF][sso_maf]
- **Уверенность:** medium

#### A02 `idle_map_high`
- **Параметры:** mapKpa, atmKpa
- **Условие:** `HOT_IDLE` 30 с и `mapRatio > 0.45`
- **Уровень:** warn
- **Водителю:** "На холостых во впуске слабое разрежение. Так бывает при большом подсосе воздуха, низкой
  компрессии или сбитых фазах."
- **Причины:** 1) большой подсос (шланг усилителя тормозов, PCV); 2) клапан ХХ / дроссель приоткрыт;
  3) AVCS заклинил в опережении; 4) ремень ГРМ перескочил; 5) низкая компрессия; 6) забитый выпуск/катализатор.
- **Проверить:** шланги, avcsDeg на ХХ, компрессия.
- **Источники:** [FSM H4SO 26.7-40 кПа][fsm_h4so], [FSM LGT 29.5-37][fsm_lgt05], [FSM WRX 24-41.3][fsm_wrx05]
- **Уверенность:** medium (норма high, причины medium)

#### A03 `na_wot_vacuum`
- **Условие:** NA, `WOT && rpm in 3000..5500 && atmKpa - mapKpa > 10` дольше 1 с
- **Уровень:** warn
- **Водителю:** "На полном газу мотор недобирает воздуха. Проверьте воздушный фильтр и воздухозаборник,
  зимой туда может набиться снег."
- **Причины:** забитый фильтр, снег/лед в заборнике, дроссель не открывается полностью (педаль, коврик, ETC).
- **Источники:** физика впуска; [FSM: throttle ~2 % на ХХ, полный ход при WOT][fsm_lgt05]
- **Уверенность:** medium

#### A04 `na_wot_load_low`
- **Условие:** NA, `PULL && rpm in 3500..4500 && load < 0.85 * expected`, где expected EJ20 = 0.95, EJ25 = 1.2 г/об
  (или своя база из первых 10 разгонов). 3 разгона подряд.
- **Уровень:** info
- **Водителю:** "Мотор набирает меньше воздуха на полном газу, чем раньше. Возможна грязь в датчике расхода
  воздуха, забитый фильтр или катализатор."
- **Причины:** грязный MAF (занижает), забитый фильтр, оплавленный катализатор (после пропусков зажигания),
  сбитые фазы.
- **Источники:** [RomRaider t6156][rr6156] (load отражает крутящий момент), расчет по объему
- **Уверенность:** low (лучше работает как тренд T06)

#### A05 `intake_heat_soak`
- **Условие:** `speedKmh >= 60` дольше 2 мин и `intakeC - ambientEst >= 25` (турбо, после интеркулера) или `>= 15` (NA)
- **Уровень:** info; warn если `intakeC >= 55`
- **Водителю:** "Воздух во впуске горячий даже в движении. Проверьте, не забит ли интеркулер или радиатор грязью."
- **Источники:** [FSM WRX 2005: допуск IAT минус наружная до +50 на ХХ][fsm_wrx05]
- **Уверенность:** low-medium

#### A06 `temp_sensor_plausibility`
- **Условие:** при пуске после стоянки ≥ 6 ч: `|coolantC - intakeC| > 8`
- **Уровень:** warn
- **Водителю:** "После долгой стоянки датчики температуры антифриза и воздуха должны показывать почти одинаково,
  а у вас разница большая. Один из датчиков может врать, из-за этого хуже пуск и расход."
- **Причины:** датчик ОЖ (часто врет на "холод", тогда ЭБУ льет лишнее), датчик IAT в MAF, разъемы.
- **Источники:** [FSM WRX 2005: проверка датчиков ОЖ и IAT][fsm_wrx05], физика остывания
- **Уверенность:** high (физика), стоянка в теплом гараже зимой может давать ложное срабатывание: проверять, что
  обе температуры не выше +30.

#### A07 `atm_sensor_implausible`
- **Условие:** `atmKpa < 60 || atmKpa > 108`
- **Уровень:** warn
- **Водителю:** "Датчик атмосферного давления показывает нереальное значение. ЭБУ может неверно считать наддув
  и смесь."
- **Источники:** [FSM WRX 2005: 73.3-106.6 кПа при зажигании][fsm_wrx05]; P2227/P2228/P2229 в списке кодов
- **Уверенность:** high

### Группа B: наддув (только турбо)

#### B01 `overboost`
- **Условие:** если есть целевой наддув: `boostKpa > target + 20` дольше 1 с. Без цели: `boostKpa > stockPeak + 15`,
  где stockPeak из таблицы 1.3 для модели или 95-й перцентиль своих разгонов + 15 кПа.
- **Уровень:** warn; danger вместе с B02 или с FBKC < 0
- **Водителю:** "Наддув выше нормы. Это нагружает поршни и может вызвать отсечку топлива. Проверьте шланги к
  актуатору вестгейта и соленоиду."
- **Причины:** 1) слетел/треснул шланг к актуатору вестгейта; 2) заклинил вестгейт или тяга; 3) соленоид или
  его шланги перепутаны; 4) "крип" на большом потоке (тюнинг); 5) холодный плотный воздух.
- **Источники:** [24subaru wiki][wiki24_boost], [RomRaider t6156][rr6156] (крип и детонация), [Cobb Datalog][cobb_dl] (±1.5 psi)
- **Уверенность:** medium

#### B02 `fuel_cut_detected`
- **Условие:** `throttlePct >= 80 && rpm in 2500..(redline-300) && injPwMs < 0.5` (или `lambda > 1.5`) дольше 0.2 с,
  а за 1 с до этого `boostKpa > 0.8 * stockPeak`
- **Уровень:** danger
- **Водителю:** "На разгоне ЭБУ отключил подачу топлива из-за превышения наддува, отсюда рывок. Не продолжайте
  разгоны в пол до проверки управления наддувом."
- **Причины:** как B01; у стокового STI 2004 отсечка наблюдалась около 17-18.5 psi
- **Источники:** [24subaru wiki: BOOST LIMIT (FUEL CUT)][wiki24_boost], [DSPORT STI 2004][dsport],
  [24subaru форум: провал при разгоне][f24_cut], [Cobb boost bulletin][cobb_boost]
- **Уверенность:** medium (признак надежный, точный порог отсечки зависит от ROM)

#### B03 `underboost`
- **Условие:** `PULL && coolantC >= 70 && rpm in 3500..5500` пик наддува `< 0.6 * baselineBoostPeak`
  (или `< 0.45 бар` для стока) в 2 из 3 разгонов подряд.
  Ветка a: `wastegatePct >= 70` = ЭБУ просит наддув, а его нет. Ветка b: `wastegatePct < 20` = ЭБУ сам не дает
  наддув (см. K14, IAT, DTC).
- **Уровень:** warn
- **Водителю (a):** "Турбина не дает положенного наддува, хотя ЭБУ его просит. Обычно это утечка во впуске
  после турбины или заклинивший вестгейт."
- **Водителю (b):** "ЭБУ сам ограничивает наддув. Чаще всего после детонации или из-за ошибки. Посмотрите коды и
  показатель IAM."
- **Причины (a):** утечка наддува (патрубки интеркулера, хомуты, перепускной клапан), вестгейт открыт, шланги
  соленоида, износ турбины. **(b):** низкий IAM, ошибка P0244/P0245, горячий впуск, режим аварии.
- **Проверить:** опрессовка впуска (держит давление около 15 с), хомуты интеркулера, шланги соленоида.
- **Источники:** [ThinkTuning boost leak][tt_leak], [SubiSpeed boost leak][subispeed_leak], [Subimods underboost][subimods_boost],
  [24subaru wiki][wiki24_boost]
- **Уверенность:** medium

#### B04 `boost_oscillation`
- **Условие:** `WOT` ≥ 2 с, rpm 3500-6000: размах колебаний наддува ≥ 15 кПа, ≥ 2 цикла
- **Уровень:** info
- **Водителю:** "Наддув на разгоне плавает. Это признак проблем с управлением наддувом или утечки."
- **Источники:** [RomRaider t6156][rr6156] (колебания и пики), [24subaru wiki: плавание ±0.1-0.2 бар при слабом преднатяге][wiki24_boost]
- **Уверенность:** medium

#### B05 `wastegate_duty_saturated`
- **Условие:** `wastegatePct >= 95` дольше 3 с
- **Уровень:** info (сток), warn если одновременно B03
- **Водителю:** "Соленоид наддува работает на пределе. Турбина или впуск не справляются с запросом."
- **Источники:** [24subaru wiki][wiki24_boost]
- **Уверенность:** medium

#### B06 `boost_leak_signature`
- **Условие:** `PULL`, ячейка rpm 4000±250, IAT ±10 °C от базы: `mafGs / (mapKpa * rpm)` выше базовой линии на
  ≥ 15 % при богатой или неизменной lambda
- **Уровень:** info (одиночно), warn как тренд T07
- **Водителю:** "Датчик видит больше воздуха, чем мотор реально получает при этом наддуве. Возможна утечка
  наддува после датчика."
- **Источники:** [RomRaider t6156][rr6156] ("VF40 показывает 300 г/с, но смесь очень богатая: утечка наддува"),
  [RomRaider t6156][rr6156] (снятие нагрузки 4.0 vs 3.6 при утечке в датчике стенда)
- **Уверенность:** low-medium

#### B07 `boost_on_cold_engine` (расширение существующего правила холодного мотора)
- **Условие:** оценка масла < 60 °C (или coolantC < 60) и `boostKpa > 30`
- **Уровень:** warn
- **Водителю:** "Мотор холодный, а вы уже под наддувом. Холодное масло хуже защищает вкладыши и турбину,
  подождите прогрева."
- **Применимость:** все турбо; EJ255/EJ257 известны проворотом шатунных вкладышей при масляном голодании
- **Источники:** [8020 EJ255][a8020], [drive2 АвтоСтронг: проворот вкладышей EJ25][d2_ej25]
- **Уверенность:** medium

#### B08 `injector_duty_high`
- **Условие:** `injDutyPct >= 85` (warn), `>= 95` (danger)
- **Водителю:** "Форсунки работают почти без пауз. Запаса по топливу больше нет, это опасно на полном газу."
- **Применимость:** турбо, обычно после тюнинга; на стоке не ожидается
- **Источники:** [RomRaider t6156][rr6156] (лучше < 90), [RomRaider IDC][rr_idc] (85), [Cobb Accesstuner][cobb_at]
  (заводские форсунки около 440 / 550 / 565 см3)
- **Уверенность:** medium

### Группа I: холостой ход

#### I01 `idle_rpm_high_warm`
- **Условие:** `HOT_IDLE && batteryV > 12.8 && rpm > 950` дольше 60 с (если статус кондиционера неизвестен: > 1050)
- **Уровень:** info, warn если ≥ 3 поездок
- **Водителю:** "Прогретый мотор держит повышенные обороты на холостых. Обычно это подсос воздуха или грязный
  дроссель и клапан холостого хода."
- **Причины:** подсос, клапан ХХ (IACV на тросовом дросселе) или электронный дроссель, неотпущенная педаль/трос,
  датчик ОЖ врет на "холод".
- **Источники:** [FSM LGT: 630-770][fsm_lgt05], [FSM H4SO: 700][fsm_h4so], [offroadsubarus IACV SG][oss_iacv],
  P0507 = обороты на 200 выше цели ([700r4 P0507][p0507])
- **Уверенность:** medium

#### I02 `idle_rpm_low_or_hunting`
- **Условие:** `HOT_IDLE`: `rpm < 550` дольше 5 с, или колебания rpm с размахом ≥ 150 и периодом 1-5 с дольше 20 с
- **Уровень:** warn
- **Водителю:** "Обороты холостого хода падают или плавают, мотор может заглохнуть. Помогает чистка дросселя и
  клапана холостого хода."
- **Причины:** грязный дроссель / IACV, подсос, после снятия клеммы не прошло обучение ХХ.
- **Проверить:** чистка дросселя и IACV, процедура обучения ХХ после сброса.
- **Источники:** [offroadsubarus IACV SG][oss_iacv], [Carista P0506][carista_p0506], [Subimods rough idle][subimods_idle]
- **Уверенность:** medium

#### I03 `idle_rough`
- **Условие:** `HOT_IDLE`, 30 с: `stdev(rpm) > 40` без периодичности I02 и `stdev(afCorrPct) > 5`
- **Уровень:** info
- **Водителю:** "Мотор работает на холостых неровно. Так бывает при пропусках зажигания: свечи, катушки или масло
  в свечных колодцах."
- **Причины:** свечи, катушки и провода (трекинг на корпусе катушки), масло в колодцах от прокладок клапанных
  крышек, подсос, форсунка.
- **Источники:** [Subaru tech tip: катушки и ВВ провода][uhs_coil], [go-parts P0304][gp_p0304]
- **Уверенность:** low (без Roughness Monitor это косвенный признак)

#### I04 `idle_timing_abnormal`
- **Условие:** `HOT_IDLE` 30 с при нормальных rpm: `timingDeg < 3` или `timingDeg > 25`
- **Уровень:** info
- **Водителю (низкий угол):** "Чтобы удержать обороты, ЭБУ сильно убирает угол. Значит, мотору на холостых
  достается лишний воздух."
- **Водителю (высокий угол):** "ЭБУ поднимает угол, чтобы мотор не заглох. Возможно, забит дроссель."
- **Источники:** [FSM: 10-15° / 14-16°][fsm_lgt05]; вывод о регулировании ХХ углом наш
- **Уверенность:** low

#### I05 `cold_idle_slow_drop`
- **Условие:** после холодного пуска `coolantC >= 60 && IDLE && rpm > 1300` дольше 2 мин
- **Уровень:** info
- **Водителю:** "Повышенные обороты прогрева держатся дольше обычного. Проверьте клапан холостого хода или
  дроссель."
- **Источники:** высокий ХХ на холодную для прогрева катализатора норма ([BITOG][bitog_idle]); переход к норме
  после прогрева по FSM
- **Уверенность:** low

### Группа C: охлаждение

#### C01 `coolant_hot` (уточнение порогов)
- **Условие:** warn: `coolantC >= 102` дольше 30 с; danger: `>= 105` (существующее); critical: `>= 110` "остановиться"
- **Водителю (warn):** "Мотор горячее обычного. Снизьте нагрузку и следите за температурой."
- **Обоснование:** Cobb считает нормой < 215 °F (101.7 °C); вентиляторы должны включаться выше 95 °C;
  заводская таблица на ХХ 80-100 °C.
- **Источники:** [Cobb Datalog][cobb_dl], [SubaruForester fan][sf_fan], [FSM LGT][fsm_lgt05]
- **Уверенность:** high
- **Разногласие:** форумы называют включение вентилятора 97-99 °C, а второй скорости 105 °C
  ([UltimateSubaru][us_fan]). Порог warn 102 с этим совместим.

#### C02 `coolant_hot_at_speed`
- **Условие:** `speedKmh >= 70` дольше 60 с и `coolantC >= 100`
- **Уровень:** warn (выше, чем перегрев в пробке: на скорости воздуха достаточно)
- **Водителю:** "На скорости мотор не должен греться выше 100 градусов. Проверьте уровень антифриза. Если он
  уходит без видимых потеков, нужна проверка прокладки ГБЦ."
- **Причины:** 1) мало антифриза; 2) радиатор забит снаружи (тополиный пух, грязь) или изнутри; 3) термостат
  открывается не полностью; 4) прокладка ГБЦ (газы в системе охлаждения); 5) помпа.
- **Применимость:** все, особенно EJ25 (DOHC 1996-1999: внутренний пробой; SOHC 1999-2011: внешняя течь, на поздней
  стадии перегрев на трассе)
- **Источники:** [australiancar.reviews][acr_hg] (перегрев на длинных трассах), [oocities HG][ooc_hg], [Subimods HG][subimods_hg],
  [Blingstrom][blingstrom]
- **Уверенность:** medium

#### C03 `coolant_hot_idle_only`
- **Условие:** `coolantC >= 100` при `speedKmh < 20`, и снижается ≥ 5 °C в течение 3 мин после начала движения
- **Уровень:** warn
- **Водителю:** "Мотор перегревается только в пробке и остывает на ходу. Скорее всего, не включаются
  вентиляторы радиатора: проверьте предохранители и реле."
- **Причины:** реле/предохранитель вентилятора, мотор вентилятора, датчик.
- **Источники:** [SubaruForester fan: оба вентилятора выше 95 °C при скорости < 19 км/ч][sf_fan],
  [FSM WRX 2005: процедура P0128 проверяет вентилятор][fsm_wrx05]
- **Уверенность:** high

#### C04 `coolant_spike_warm` (существующее, оставить)
- **Условие:** `+8 °C за минуту` при старте 80-98 °C и прогреве > 5 мин
- **Добавить:** если повторяется в ≥ 3 поездках после прокачки, повысить до warn с текстом про прокладку ГБЦ;
  "пузыри в расширительном бачке" как подсказка что проверить.
- **Источники:** [forum.24subaru: пузыри и тосол из бачка][f24_hg], [Subimods HG][subimods_hg], [BITOG][bitog_hg]
- **Уверенность:** medium

#### C05 `coolant_sawtooth`
- **Условие:** `CRUISE` 10 мин: ≥ 3 качелей температуры с размахом ≥ 6 °C, или падение ≥ 8 °C быстрее 30 с при
  `coolantC >= 80`
- **Уровень:** warn
- **Водителю:** "Температура антифриза скачет вверх и вниз на ровном ходу. Это бывает при воздушной пробке,
  залипающем термостате или газах в системе охлаждения."
- **Причины:** воздух после замены антифриза, залипающий термостат, прокладка ГБЦ (выхлоп выдавливает антифриз
  мимо датчика), низкий уровень.
- **Источники:** [Subimods: короткие скачки стрелки][subimods_hg], [BITOG: газы выдавливают антифриз в бачок][bitog_hg]
- **Уверенность:** low-medium

#### C06 `thermostat_stuck_open` (уточнение существующего)
- **Условие (сейчас):** 20 мин движения, coolant < 72. Добавить: при `ambientEst < -15` давать 30 мин;
  отдельно: прогретый мотор (`coolantC` был ≥ 85) на трассе падает и держится < 75 дольше 5 мин.
- **Водителю:** "Мотор остывает на ходу. Похоже, термостат не закрывается. Зимой это значит холодную печку и
  повышенный износ."
- **Обоснование:** заводской термостат EJ начинает открываться около 76-80 °C (169-176 °F) и полностью открыт
  около 91 °C (196 °F); каталожный Gates для SG 2.5 NA: 82 °C. Subaru P0128 ставит после 2 поездок
  подряд, сравнивая фактическую температуру с расчетной.
- **Источники:** [SubaruForester: thermostat][sf_temp], [Superspares Gates SG 82 °C][gates82],
  [FSM WRX 2005: P0128][fsm_wrx05], [SuCross: логика P0128][sucross_p0128]
- **Уверенность:** medium
- **Разногласие:** данные по температуре открытия расходятся (76-84 °C начало, 91-95 °C полное). Порог 72 °C ниже
  всех вариантов, поэтому безопасен.

## 5. Чего мы не видим и что добавить

### 5.1 Честно о пределах

- **Механика**: прогар перемычек поршня (ringland), проворот вкладышей, стук шатуна, износ колец. По данным ЭБУ
  видны только косвенные признаки (детонация, падение мощности). Нужна компрессия и пневмотест
  ([NASIOC ringland][nasioc_ring]).
- **Прокладка ГБЦ**: внешняя течь на EJ25 SOHC не дает признаков в данных, пока не упадет уровень ОЖ
  ([oocities][ooc_hg]). Внутренний пробой виден только косвенно (C02, C04, C05, T08).
- **Расход масла и давление масла**: датчика давления нет (только лампа), температура масла только оценка.
- **Пропуски зажигания по цилиндрам**: стандартные параметры их не показывают, I03 лишь догадка.
- **Реальный AFR на полном газу (турбо)**: штатный датчик врет под наддувом, нужен широкополосный после турбины
  ([RomRaider t6156][rr6156]).
- **Датчик детонации один** и слышит всё: стук поршней на холодную, экраны, ремень ГРМ. Отличить настоящую
  детонацию от шума можно только повтором в той же зоне.
- **Состояние кондиционера, передачи АКПП, потребителей**: влияют на ХХ и MAF, если параметры недоступны,
  пороги I01/A01 должны быть шире.
- **Целевой наддув**: без параметра цели B01/B03 работают по базовой линии своей машины.

Разногласия источников, которые стоит помнить:
- Норма A/F learning: ±5 (RomRaider идеал), ±10 (Cobb), ±15 (FSM на ХХ, и это же упор).
- FLKC: Cobb допускает до -2.8, RomRaider считает проблемой всё хуже одного шага (-1.4).
- Термостат: начало открытия 76-84 °C, полное 91-95 °C по разным пересказам мануала; каталог Gates 82 °C для SG NA.
- Вентилятор: 95 °C по пересказу FSM, 97-99 °C по форумам.
- Сетка банджо-болта турбины/AVCS: один пересказ бюллетеня говорит "чистить или заменить", другой (import-car)
  говорит про болты без сеток. Приложение советует только "проверить сетку", без рекомендаций удалять.
- Фазы EJ25 и тип пробоя ГБЦ: источники путают, какой Phase DOHC, а какой SOHC; надежно только: DOHC EJ25D 1996-1999
  чаще внутренний пробой, SOHC 1999-2011 чаще внешняя течь.

## Дополнение: масло, давление и температура (2026-10-16)

- **Давление масла на EJ ЭБУ не читает.** Лампа на щитке включается простым выключателем давления, проводом прямо на щиток. Срабатывание по заводскому мануалу: **14,7 кПа (0,15 кгс/см², 2,1 psi)**. Норма давления на масле 80 °C: **не меньше 98 кПа на 800 об/мин и 294 кПа на 5000 об/мин** ([Impreza 2001 FSM, LU][fsm_lu01], [Forester 2001 FSM, LU][fsm_lu_for01]). Лампа горит при давлении примерно в 7 раз ниже минимальной нормы, то есть почти при нуле: это сигнал «глушить сразу», а не раннее предупреждение. Для раннего предупреждения нужен отдельный датчик давления ([Crawford: выключатель знает только одну точку][crawford_op]).
- **Температура масла на большинстве EJ не измеряется.** Приложение оценивает её по ОЖ с задержкой около 5 минут. Прогретое масло горячее антифриза: стоковый STI на трассе около 105 км/ч показал масло около 106 °C ([Mishimoto, тест STI 2013][mishimoto_sti]); производители маслорадиаторов дают 85–102 °C в смешанной езде ([TR Concepts][tr_oil]). Поэтому оценка смещена вверх от ОЖ на величину, растущую со средним расходом воздуха за последние минуты: атмо `8 + 0,25 * MAF`, турбо `10 + 0,3 * MAF` °C (не больше 35), полностью с ОЖ 75 °C. Базовые 8–10 ° взяты из отзыва владельца с настоящим датчиком (2026-10): прежняя модель отставала от реального масла минимум на 10 °. Прогрев мотора приложение считает по ОЖ 80 °C: на этой температуре EJ заканчивает прогревное обогащение. Уверенность: low-medium, это модель, а не измерение.
- На ЭБУ с настоящим датчиком масла (параметр RomRaider P122, FA/FB) берётся значение ЭБУ без поправок.
