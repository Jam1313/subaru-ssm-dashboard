# Цветной экран по USB (ESP32-S3)

Отдельное USB-устройство рядом с кабелем ЭБУ и платой датчиков: плата на ESP32-S3 со своим AMOLED или IPS экраном.
Приложение само рисует страницы (те же дизайны стрелок, что на карточках, плитки, крупную цифру, список) с любыми
значениями: ЭБУ, коробка, поездка, GPS, датчики SensorBox, параметры с вкладки «Датчики». На экран уходят только
изменившиеся куски, плата их только выводит. Новый вид не требует новой прошивки.

Настройки, вкладка «Цветной экран»: выбор платы, прошивка с магнитолы, поворот, яркость, страницы, смена страниц
(кнопка BOOT на плате, по времени), показ тревоги (значение за пределом нормы открывает свою страницу).

## Протокол

USB самой ESP32-S3 (Hardware CDC and JTAG, 303A:1001), строки до `\n`.

| Кто | Строка | Смысл |
|---|---|---|
| приложение | `?` | кто ты → `I USBSCREEN 1 board=<id> w=<W> h=<H> round=<0\|1> fw=<N> id=<MAC>` (по id у каждого экрана свои настройки) |
| приложение | `P <x> <y> <w> <h> <n>` и n байт | прямоугольник (до 16384 точек, края чётные), точки построчно в RGB565 little-endian, упакованы: байт h, при h & 0x80 повтор (h & 0x7F) + 1 точек одного цвета (2 байта), иначе h + 1 точек как есть; ответ `K` или `E` |
| приложение | `B <0..255>` | яркость |
| приложение | `Z` / `H` | чёрный экран / «я на связи» |
| экран | `N` / `L` | кнопка BOOT коротко / долго: следующая страница |
| экран | `Y R` | 5 с не было строк (на экране NO LINK), прислать всё заново |

## Прошивка

С магнитолы: кнопка «Прошить экран». Приложение переводит ESP32-S3 в загрузчик ROM линиями DTR/RTS (как esptool),
пишет склеенный образ с адреса 0 блоками по 1 КБ и сверяет MD5. Загрузчик в ПЗУ, испортить его нельзя. Новая плата с
чужой прошивкой может не перейти в загрузчик сама: зажать BOOT, вставить USB или нажать RST, отпустить BOOT.

Пересобрать после правки: `./build-bin.sh` (нужен `arduino-cli`, ставит пакет esp32 3.3.10 и Arduino_GFX 1.6.9).
Скрипт пишет `bin/usbscreen-<id>.bin` и `bin/manifest.json`; юнит-тест не даст выпустить приложение со старыми файлами.
